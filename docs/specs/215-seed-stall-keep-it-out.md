## Purpose, model and pictures

The storm market is sorting a mixed seed parcel. Its pictured screen bag contains six equal-chance counters, two sun and four moon. A trial draws **two** seeds. Compare two explicit rules: **Keep the first out** (second selection among the five remaining positions) and **Put it back** (second selection among all six positions). Restore the full bag before the next trial in either rule. Mark/color and text both identify a seed. A large bag, first/second tray, remaining counts and a short question are the center of the screen; step labels explain what is about to happen. These are screen trials under a stated uniform rule, not observations of real seeds or a fairness test.

First and second draws are separate deliberate presses. The first stays visibly in the tray. In keep mode its original bag position is empty and the next-draw count is five; in return mode a small “returned” label makes clear why all six positions are again available. The last completed pair stays visible until the next trial's first draw. There is no decorative shuffle, hidden predetermined outcome, timer or batch auto-draw. Uniform randomness uses rejection sampling over six or five available positions; a keep second draw maps its sampled index through the remaining original indices, never `%5` on the old six-selector. Unavailable entropy refuses without changing the current trial. Tests inject deterministic entropy only through an explicit test option; production uses Web Crypto.

Three freely accessible pages, **Draw pairs / Chance tree / Results**, preserve work across navigation. Mode buttons on Draw pairs select the waiting run of that rule. Start a new 15-trial set only if no unfinished set exists for that mode; at most three sets per mode, six total. Prediction is optional and unscored (`ss`, `mixed`, `mm`, `unsure` or null), editable before its set's first draw only. Draws record original slot indices, not just mark names. A pending first draw survives leaving, reload, mode changes and explorer switches. Completing trial15 disables further draws; choose a completed set to inspect or another available mode/set. This slice has no silent reset, eviction, unconstrained run growth or replacement of earlier sets. Short finite sets are deliberate teaching encounters; replay beyond these caps needs a separately reviewed retention choice.

A two-stage **illustrated tree explorer** lets a learner deliberately choose the first mark, then a second mark, to inspect a branch. Its buttons say “Explore a sun-first branch,” never “Draw.” It is visibly labeled **Choose a path, not a random trial**. It shows the first bag, the remaining bag under the chosen rule, and the two branch fractions as counts. Before a deliberate branch selection, no branch is implied to have occurred. It creates no random result or independent-answer observation. The ordered keep paths are SS 2/30, SM 8/30, MS 8/30, MM12/30; joining the two mixed paths gives16/30=8/15. Return paths SS4/36=1/9, SM8/36=2/9, MS8/36=2/9, MM16/36=4/9. Both mixed orders must remain visible before joining them.

Results count only completed pairs. Bars share a fixed zero-to15 baseline and text counts; show how many of15 are completed. Missing trials are absent, never counted as a mark. Keep-mode expected counts **1,8,6** are labeled averages over many 15-trial sets, never a target this run must meet. Return-mode results show exact theoretical fractions1/9,4/9,4/9 but omit expected counts for15 (they are nonintegers5/3,20/3,20/3). Do not reuse the keep averages for return mode. A note says each new trial starts with2sun/4moon, so a string of earlier trials does not make an outcome “due.” No expected-versus-observed mismatch is graded.
