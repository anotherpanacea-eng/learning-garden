## The new operation

Repartition **two fixed fractional amounts** until their pieces use one common unit, then compare the counts of those equal-sized pieces. Both original wholes have the same drawn size. Neither the whole nor either shaded endpoint moves when cuts change. A larger count after subdivision names the same amount; it does not add ribbon.

Lantern Line already compares unlike fractions, including3/4 versus2/3. Recut100 already reversibly repartitions one amount. Matches70 reconstructs an equivalent target; Join103 moves like-size pieces; Field Strips290 takes a fraction of a fraction. This release adds the two-amount common-unit construction connecting those experiences. It does not introduce generic fraction comparison for the first time, commission the whole proposal196/PR158 pack, implement unlike-denominator addition, or establish a learner's general understanding.

Use a small transient table beside Recut, not a new assessed notebook or grading engine. All fractions, counts and comparison explanations are supplied model readouts. Human explanation is welcome and ungraded. No score, timer, required quiz, mastery/grade/age gate, adaptive placement, learning receipt, new atlas claim, story contribution or actual craft measurement.

Every job is freely selectable. All fractions refer to a same-sized whole from0 to1; two ribbons can have different shaded amounts while their full lengths remain identical. A and B retain pattern and letter labels independently of colour.

Neither original numerator nor endpoint is an editable answer. On each ribbon separately, native **Split each piece in2**, **Split each piece in3**, and **Undo last cut** manipulate dividing marks. Splitting replaces every current equal space with2 or3 equal spaces. It multiplies both counts by that factor, preserves every old boundary, adds the intervening boundaries and keeps the shaded prefix fixed. Undo reverses only that ribbon's most recent split; it does not remove ribbon or change the other ribbon. Refuse an unavailable action; never clamp it into a different action. Split disables if its resulting denominator would exceed12; Undo disables on an empty history.

All mathematically valid subdivision branches stay open: an eighths or ninths detour is exploration, not an incorrect answer. Common sixths and twelfths are both accepted where reachable; no least-common-denominator preference. Undo lets a learner change course. Keep original and current names visible together without automatically simplifying. The exact denominator is original denominator times the product of its factor history; coloured count is original numerator times that same product. Histories contain only2/3 and must keep every denominator≤12. They are bounded in-memory controls, not imported/save data. Internal transient field names/layout are implementation choices, not a versioned artifact contract. For drawing,72 internal positions cover the whole: endpoint=72×original numerator/original denominator; current boundaries=j×72/current denominator. Every reachable point is integral. These coordinates are not72 visible pieces or physical units.

Each ribbon keeps its own last-action annotation. After a split, dashed marks are newly inserted boundaries and solid marks survived from the immediately previous partition. After Undo, only the surviving larger-space boundaries remain and all are solid. The brass endpoint flag, shade/pattern extent and whole are constant. A1/2 strip becoming3/6 does not stretch, add shade or change which amount reaches farther.

## Comparison and help

**Compare the pieces** is an explicit optional action, always available after choosing a pair. If current denominators match, supply the equal-unit counts, matching-unit fraction names, relation and meaning. If they differ, explain that comparing the coloured-piece counts alone cannot settle the amount because those pieces differ in size; invite matching them or using the fixed endpoints. Do not call the construction wrong, withhold the ribbons, imply other comparison methods are invalid, or pretend the comparison was the child's answer. Further cuts/Undo hide that optional comparison until requested again. No kept result or repeated-attempt count.

A separate three-picture example is1/2 versus1/4, never a live pair. Picture1 has original halves and quarters; picture2 splits only A's halves in2, giving2/4 versus1/4; picture3 undoes that cut. Fixed endpoints and equal whole lengths remain visible in every picture. Native Previous/Next controls change the actual diagram and readout, not only prose. Both directions remain available within bounds; no auto advance. Example actions do not change any live pair. Help is optional and never automatically completes the chosen construction. Explain the same-whole/equal-piece bridge on the main board so prior visits and multiplication recall are unnecessary.
