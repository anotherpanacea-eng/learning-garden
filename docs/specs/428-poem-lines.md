## Work and operations

Pure content/core/UI/CSS modules `poem-lines-{content,core,ui}.mjs` and `poem-lines.css`. No notebook writer. A visit is owned by the exact notebook object and explorer ID, with separate temporary work per poem, current screen, selected word and example frame. Reload, route departure, explorer picker/switch/import/reset discard this visit, as explicitly stated. Changing pages, changing poem and visiting the example **within this bench** retain each poem’s own work. Unknown `poemLines` notebook data stays exact and exportable; no loader “repairs” it.

Each poem’s work is `{breaks:[sorted unique integers1..N-1], pauses:{[position]:'brief'|'long'}, previous:null|{breaks,pauses}}`. Pauses are at inter-word positions1..N-1 independently of breaks. No terminal pause tool. No arbitrary string keys, fractional/duplicate/out-of-range positions or other enums accepted. Snapshot copies contain breaks/pauses only; single-level Undo restores both and clears history. A material action which has no effect is a no-op and does not replace history. Validate against the selected immutable current poem solely because this is new temporary work, never historical save validation.

- **Select a word:** tap a word button on the poem paper, or use labelled native **Word to change** select. Options include position and token (“2: leave”), distinguishing repeated words. Selection is not a material edit and keeps history. Default selected word1. Last word may be selected for reading, but its break/pause controls are disabled with **The last word already ends the poem. Choose an earlier word.**
- **End line here / Join next line:** toggle break after selected word. If removing a break, the following words join that printed line; words/order/punctuation never change. Label changes with the state; no automatic pause is added/removed.
- **No pause / Brief pause / Longer pause:** native three-button choice, aria-pressed; choosing same value is a no-op. Remove pause means absent key. These are reminders for a human reader, with no fixed duration and no recording. Represent brief by a small “pause” note, long by “longer pause”, visually separate from immutable words; do not insert slash/punctuation into the poem.
- **Undo last change:** one-level material undo, disabled when unavailable with **No layout change to undo.** Selection stays at the same word.
- **Start this layout again:** restore A breaks and no pauses, undoable if it changes work. It affects this poem only and never switches the poem. Clearly label it as resetting this temporary arrangement, not learner history.
- **Compare layouts:** opens a separate comparison page with Own arrangement and supplied A or B. Default A; **Show layout A/B** changes reference only. Own material/selection/history remain untouched. **Back to my poem** restores editor, selected word and focus. No fitting/wrong feedback, green success marks or automatic next poem. Reference notes are exactly the finite table’s note. The fact that both references are accepted does not mean every imagined effect has textual support; discuss with a person.
- **Show a separate example:** opens five manual teaching frames; preserve work/selection. Previous/Next disabled at ends. Back restores caller (editor or comparison) and its selected reference. Example cannot be edited or exported as child work. Its IDs are not live poem IDs.
- **Take a paper copy:** native local `.txt` download of the selected own arrangement, preserving each authored break as newline and punctuation exactly; separate section lists pause plans by word position and token. Include title, “Arrangement of supplied words”, and “Pause notes are plans for a person; no performance was recorded.” No timestamp, identity, notebook, answer record or hidden supplied reference. Export current own material from editor or comparison only; no save call. The browser must inspect actual download bytes. Declining a download does not affect work.

## Separate teaching pictures and exact core copy

Example words (not a live card): **We hold the door; the wind comes in.** (8 tokens). Frames:
1. Single printed line; **These are the words. A sentence and a printed line are different things.** No pause plan.
2. Break afterhold(2): two lines. Highlight that boundary; **The first line ends after “hold”, but the sentence continues. We still need to learn what is held. Carrying a sentence across a line ending is called enjambment.**
3. Same breaks, no automatic pause. **A line ending can draw attention without a full stop in the voice. Read across it once. Then try a small pause. Neither reading changes the printed words.** A brief optional pause mark afterhold is shown as a planned alternative in this frame, not played or graded.
4. Single printed line, brief pause plan afterdoor;(4). **The semicolon is inside this line. A pause within a poetic line is called a caesura. Punctuation can suggest it; a performer also makes choices.**
5. Two identical single-line layouts side by side, one pause plan atdoor;(4), one longer plan there. **The same printed line can have different readings. Try both with someone. Our pause notes do not measure time or prove a performance happened.**
