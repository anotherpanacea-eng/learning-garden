## Three open challenges and meaningful returns

The learner chooses **Forces and motion**, **Read collision evidence**, or **Choose and revise a design**. A local suggestion explains its narrow basis, and every alternative remains available. Forces/motion has six cases. Each supplies left/right horizontal forces from 0/2/4/6/8 N, mass fixed 2 kg, signed initial velocity −3…+3 m/s, one second of constant force, and three items: signed resultant, signed acceleration, final velocity. Include balanced moving-left and moving-right cases, acceleration opposing motion with continued original direction, reversal, rest with nonzero acceleration, and acceleration in the same direction as motion. Formula: Fnet=right−left; a=Fnet/2; v1=v0+a×1s. Right positive, left negative; vertical forces balance; friction/air resistance omitted. Wrong alternatives include resultant sum/cancellation, velocity mistaken for acceleration, immediate reversal and no-change where appropriate. Numeric options have equal units and vary matching position.

Collision evidence has six controlled invented tables. Within each table the same 2 kg cart has the same starting speed and stops at zero with the same target/measurement method; between tables starting speed, stopping times, deformation, token cost and depth change. Average net stopping force magnitude=m×|Δv|/Δt; direction opposes starting motion. Each has measured shape/time, calculated averages and three observation/model/unsupported items with rotated category options. Include a cautious-but-wrong claim that the supplied measurements tell us nothing about average force under the stated model. No peak-force/injury/durability inference. Tables are invented, never measured results or real safety claims.

Design has six tables/briefs using the same collision controls. Initial and revised cost/depth constraints are explicit; first filter both constraints, then select the unique fitting minimum average magnitude. Every revised brief changes the fitting winner; source tests derive keys from frozen numbers. Explain/keep original, reveal changed constraint, choose again, revise/keep: original writing remains exact, human-read and ungraded. Table metadata freezes mass/start/end speed and constraints, so captions never silently use the fixed lesson's numbers.
