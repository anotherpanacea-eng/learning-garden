# 221 · Les pièces et les projets

Four original open French lessons at `#learn/french`, coherent fictional shared-house room plan and returning message. Short manageable French sentences with older meaning: help someone find an object, resolve ambiguity and report recent/coming actions. Every passage has aligned English meaning available **only on demand**; request recorded as support. Local French TTS optional via existing speech layer, no English fallback. No native-audio, phonics, fluency, mastery or original-writing grade claims.

## Full finite content

Plan fixed north/up: two columns, two rows. Top left **le salon**, top right **la cuisine**, bottom left **la chambre**, bottom right **l'entrée**. Furniture/object buttons inside rooms: salon `la table`, `la lampe` (on table), `le livre` (under table), `la chaise`; cuisine `l'étagère`, `la tasse` (on shelf), `la petite table`; chambre `le lit`, `le sac` (beside bed); entrée `la porte`, `le manteau` (behind door). Render placement diagrams as well as exact text, object selection never depends only on graphics. Directions relative to plan page, not walker perspective.

1. **Lire le plan.** Passage: “Voici le plan de la maison. Le salon est à gauche de la cuisine. La chambre est sous le salon sur le plan. Dans le salon, il y a une table et une chaise.” Meaning: Here is the house plan. The living room is to the left of the kitchen. The bedroom is below the living room on the plan. In the living room there is a table and a chair. Teach `la pièce` = room; `dans` = in; plan position versus object position explicitly. Guided: “Où est la tasse ? Elle est dans la cuisine.” / Where is the cup? It is in the kitchen. Task “Choisis la pièce où se trouve le lit.” choices salon / chambre / cuisine, correct second. Hint: “Cherche le meuble pour dormir.” / Look for the piece of furniture for sleeping. Different example: “La porte est dans l'entrée.” / The door is in the entrance hall.
2. **Donner une position précise.** Passage: “La lampe est sur la table du salon. Le livre est sous cette table. Le sac est à côté du lit. Le manteau est derrière la porte.” Exact meaning: lamp on living-room table, book under that table, bag beside bed, coat behind door. Teach sur/on, sous/under, à côté de/beside, derrière/behind. Guided trace: “Entre dans le salon. Cherche sous la table. Tu trouves le livre.” / Enter the living room. Look under the table. You find the book. Task “Dans le salon, choisis l'objet qui est sur la table.” choices lampe / livre / sac, correct first. Hint “« Sur » n’est pas « sous » : cherche ce qui est posé sur la table.” / “On” is not “under”: look for what is resting on the table. Different example “La tasse est sur l'étagère, dans la cuisine.” / The cup is on the shelf, in the kitchen. Second task “Pars de l'entrée. Va dans la pièce à gauche sur le plan, puis dans la pièce juste au-dessus. Où arrives-tu ?” / Start in the entrance hall. Go into the room to the left on the plan, then the room just above. Where do you arrive? choices cuisine / chambre / salon, correct third. Guided/hint/example separately: follow entrée→chambre→salon; hint move one room at a time; different example cuisine→salon→chambre. Task keeps full map visible; no door/wall feasibility claim, arrows indicate reading positions.
3. **Demander une précision.** Passage: “Un message dit : « Pose le carnet sur la table. » Mais il y a deux tables : une dans le salon et une dans la cuisine. Tu peux demander une précision avant de choisir.” / A message says: Put the notebook on the table. But there are two tables: one in the living room and one in the kitchen. You can ask for clarification before choosing. Teach ambiguity is insufficient location, not failed reading. Guided “Quelle table : celle du salon ou celle de la cuisine ?” / Which table: the one in the living room or the one in the kitchen? Task choose useful clarification: “De quelle couleur est le carnet ?” / “Quelle table : celle du salon ou celle de la cuisine ?” / “À quelle heure faut-il poser le carnet ?” correct second. Hint need room, not color. Different example “Près de quelle porte ?” / Near which door? Clarification reveal “Sur la table du salon, à côté de la lampe.” / On the living-room table, beside the lamp. Second task select final location: table du salon / petite table de la cuisine / lit de la chambre, correct first. Each item has separate guided/hint/example/skip. Interactive place-notebook control uses the table du salon, petite table de la cuisine and lit de la chambre and echoes the chosen room/object.
4. **Un retour et un projet.** Initial passage “Je viens de rentrer. Je viens de poser le carnet sur la table du salon. Je vais chercher le sac dans la chambre. Ensuite, je vais revenir dans le salon.” / I have just come home. I have just put the notebook on the living-room table. I am going to get the bag in the bedroom. Then I am going to return to the living room. Teach recent past `venir de + infinitif` and near future `aller + infinitif`, present first-person forms only: je viens de / je vais. `de` becomes `d'` before a vowel, example “Je viens d'arriver.” This is a usage aid, not a test of all conjugations. Guided: “Je viens de rentrer” happened just before now; “je vais chercher” planned next. Task “Quelle action est prévue ?” choices rentrer / poser le carnet / chercher le sac, correct third. Hint `je vais` marks planned next action. Different example “Je viens de lire le message. Je vais répondre.” / I have just read the message. I am going to reply. Original message field max 1200 characters, ungraded, invitation use one recent action and one plan, keep original. New message revealed on request: “Le sac n'est plus à côté du lit. Je viens de le mettre dans l'entrée, derrière la porte.” / The bag is no longer beside the bed. I have just put it in the entrance hall, behind the door. Second task “Où vas-tu chercher le sac maintenant ?” choices entrée / chambre / cuisine, correct first. Hint new message changes bag location; different example if a book moves to kitchen, use new location. Revision field retains exact original and revision separately, first/latest snapshots. Map updates bag only after message reveal, with “nouveau message / new message” label; initial source map still recoverable in notes.
