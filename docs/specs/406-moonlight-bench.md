## Finite model and state

Pure core `dist/moonlight-core.mjs` exports `createMoonlight(orientation='north')`, `changeMoonlight(work,action,value)`, `moonlightModel(work)`, `moonlightNarration(work)`. Work exact own fields `{position:integer0..7,revealed:boolean,orientation:'north'|'south',page:'explore'|'teaching',step:integer0..3,invitation:integer0..3}`. Explore requires step0. Plain own-field objects; unknown/extra/inherited/accessor fields, invalid types/ranges/enums return null, not throw. Sources are module-owned. Initial position0, revealedfalse, pageexplore, step0, invitation0; orientation north unless caller gives south. State/factories/results are detached from inputs/source.

Explore-only actions: `position` selects another index; `next`/`previous` wrap0..7; `reveal` toggles revealed; `flip` toggles orientation; `invitation` advances modulo4, leaving position/revealed/orientation exact. Position changes retain revealed: a child can choose to keep the Earth view open to watch it change. `teaching` enters step0; `step` chooses0..3 only in teaching; `explore` restores own work and resets step0. Same position/page/step is a no-op returning null; unknown/invalid/disallowed actions also return null. Same teaching page is a no-op even at later steps. Value-less actions accept only undefined; position/step alone accept their stated integer value. createMoonlight(anything other than south) starts north. Teaching Previous/Next stop at steps0/3 with disabled boundary controls, not wrapping. No model position changes while teaching. No answer/check/outcome/attempt/support flag exists.

`moonlightModel` returns exactly `{page,step,position,location,point:{x,y},phase,orientations,teaching,invitation,showingExample}`. `position` is the elected display index (own in explore; card.position in teaching), location/point are its source-owned diagram location/center. `phase` is null in explore-hidden, otherwise detached `{code,name,description,amount}`. `orientations` is [] in explore-hidden, [own orientation] in explore-revealed and teaching steps0–2, [north,south] in teaching step3 (fixed order). `teaching` is null in explore, otherwise detached `{title,text}` for selected card; `invitation` is current invitation string in explore and null in teaching. `showingExample` is true only in teaching. No source object containing hidden phase fields is returned. Help never mutates own work.
