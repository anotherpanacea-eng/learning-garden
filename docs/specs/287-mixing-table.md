## Mathematical display toy, not paint physics

`toy-scoop-rgb-v1` is an openly defined digital display rule. An equal scoop is one model unit; no mL, mass, real pigment strength or measured mixture volume. Each frozen ingredient has a label, pattern and integer RGB endpoint: white[244,240,223] dots; blue[48,91,148] stripes; yellow[240,198,58] crosshatch; red[194,67,55] chevrons. A nonempty pot(a,b) displays each channel as `Math.round((a*A+b*B)/(a+b))` (nonnegative half-up rounding), using its source-owned ordered endpoints. No stochastic behavior, nearest named shade, physical interpolation claim or uncatalogued dead end. This rule intentionally replaces proposal201's nonresponsive unknown-swatch case. All ratios retain full numerical/pattern feedback, including unnamed toy colors.

**Comparison truth is never RGB or visual similarity.** With same ordered ingredient pair, positive target(u,v) and a+b>0, exact same ratio is `a*v === b*u`. Products are at most576 with24 bounds. Display color rounding can give identical pixels to different ratios; say so in grown-up help and use counts/cross-products for every comparison. Every stripe also shows ordered counts, ingredient patterns and text Same/Different proportions; a color-vision difference or poor display cannot hide the result. A proportion band draws a fixed240-unit bar split at `240*a/(a+b)`, labelled total scoops plus the actual count of each named ingredient, with pattern key. This is an exact-ratio diagram subject to finite screen resolution, never a separate measurement. Pure endpoints show one full band. Empty shows two zero counts and no stripe/band ratio.

Adding equal k to positive(a,b) preserves ratio iff `k*(b-a)===0`; thus positive equal addition preserves1:1, but changes2:3. Adding0 changes nothing. Do not write “adding the same always changes ratio,” “more of both keeps it,” or imply only whole-number scale factors connect equivalent pairs:4:6→6:9 scales by1.5. The sample2:3 multiplied by whole group counts supplies a useful early construction, not the definition of every equivalent-ratio transformation. Unordered pair/color swaps are not equivalent.

Optional **Show groups** displays as many whole sample groups as fit, `min(floor(a/u),floor(b/v))`, with all leftovers explicitly pictured/listed. Zero groups is not an error. For current counts not whole sample multiples, leftovers remain: no fractional scoops or forced simplification. **Show a table** shows the source's sample, ×2,×3,×4 where both counts<=24, plus the actual pot in a separately labelled row. For wb2:3, blue/white is3/2=1.5 for the supplied equivalent rows. Ratio order is white:blue, so blue=(3/2)×white; never inherit the reversed a/b formula for x:y=a:b. For current white0 say division is undefined, not Infinity/0; positive actual pairs can display exact ordered ratio a:b and the unreduced fraction b/a, without requiring decimal computation. No graph, general formula entry or table grading.
