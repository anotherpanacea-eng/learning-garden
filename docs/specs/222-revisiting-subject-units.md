## Learner experience

Each existing unit keeps its fixed lessons and saved sources. A return changes meaningful material: mathematical quantities/unknowns, complete authored English text and reader purposes, science model/data/constraints, or French locations/messages/actions. No live AI generation, remote learner upload, names, ages, grades or external API is needed.

Use recent *distinct case/item* responses to suggest either a supported revisit, a nearby contrast, or a more involved application. ## Source and save contract

New work freezes the complete source, ordered choices/key/feedback, model, support and any generation/selection metadata on explicit creation. Render/notes/suggestion reads are pure. Fresh sources are original and finite or generated from reviewed bounded parameter spaces; never regrade stored results or rebuild a waiting source from today's generator. Older fixed work, first/latest kept drafts and unknown raw siblings remain intact. Malformed optional exploration metadata closes only new-case selection where necessary, not readable existing work. Imported strings are escaped and ids/routes bounded.

All mutations require the actual pretty-notes-report import preflight plus shared limits, and commit only the owning subject root. Refusals leave everything unchanged. Existing display fact-qualification and French speech support gates remain effective. No silent history eviction, truncation or overwrite. If space is needed, offer the existing notes download and an explicit, confirmed removal of a learner-selected generated visit (including an accurate warning about its drafts/kept writing); fixed lessons remain protected. Do not create a second backup system. A portable-file limit is not an educational finish line.

Each unit's binder owns its route/explorer/stale controls, keeps instructions and feedback near the active task, and preserves writing across pages/returns. Tap and keyboard controls work at320/820, with local focus after help/check/skip. Existing subject selection and deep-entry previews remain open and save-neutral. No artificial "Next" that silently discards a current draft.
