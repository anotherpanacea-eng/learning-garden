## Teaching and three open turns

One active task sentence, drawing and controls; tabs plus Previous/Next are always open. No timer, score, automatic advance, correct route, pass or required help.

**Compare the records.** The original two dot plots share the SAME axis and unit pitch, with source table one tap away. Mean, Median and Range are large highlight buttons, not answers. The chosen summary highlights each group's value or endpoint distance and is named beside the plot. A compact center-and-spread table always gives n, mean, median and range for BOTH original groups; do not hide spread just because Mean is selected. Count and Recorded minutes are table headings, not extra highlight buttons. Optional Show how opens exact sum/count, ordered middle selection and max−min workings for each original group. Explain the center used and range's endpoints-only limit; range does not describe every detail. Different means do not alone describe different spreads, and equal means do not make the observations identical.

**Look closer.** In source1, inspect the explanation for f7. “Set it aside in a comparison” toggles a secondary calculation for Ford, displayed beside its unchanged all-record calculation. The original source and values never change. Plot positions stay based on original records; the set-aside marker becomes hollow with a cross and a text key, never invisible. The selected highlight can use secondary Ford values ONLY on this turn, explicitly labelled “Secondary comparison · f7 set aside.” Original Ford summaries stay adjacent and labelled “All seven recorded trips.” Clearing the toggle restores the original calculation, not a new catalogue. Say: the mean changes40→34, median34→33.5, range45→7; this describes these lists only. Quote the frozen comparison note without classifying a historical record as long, delayed, normal or erroneous. The authored closure note explains its wait, but a surprising value alone is not a mistake. This secondary comparison omits one specified observation and therefore answers a narrower question. It does not identify all trips under some condition or establish future probabilities. A different set need not leave its median unchanged. For historical sources, derive both before/after values from that frozen source and apply the comparison to its OWN referenced group, not necessarily Ford or the second group. Never use catalogue ids as arithmetic or prose truth.

Source2: no exclusion button, no invented exceptional record. The centers-agree sentence appears only when the actual two means AND medians agree by exact arithmetic, never merely because a source id is market-parcels. Show the same two original distributions and ask which summary alone would hide their different spreads. The center-and-spread table remains available. Historical invalid optional comparison metadata is isolated: show that an earlier secondary choice is retained but cannot be reconstructed; continue showing only explicitly labelled original summaries. Do not silently label original values “secondary.” In an editable retry, an explicit Use all records can clear a retained `aside:true`; it cannot invent a referenced record.

**Make a case.** Choose a purpose card: typical recorded trip / total time in these records / variation in recorded times. Purpose is an ungraded selection, never a keyed route recommendation. Keep original center-and-spread summaries beside the chosen purpose; if `aside` is true and readable, show the secondary figures (including range) separately and restate the omitted id/value/note.
