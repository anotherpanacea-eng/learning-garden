## Purpose and boundary

## Finite English and meaning contract

Every scene explicitly establishes the pictured three as the complete local group: **“These are the three {couriers/parcels/books} in this made-up scene.”** A, B and C are diagram labels, not learner names. All pictures/facts stay fixed when wording changes. The main predicate is future information stated by the message; no scene observation claims the future action already happened.

Prepared strings and source sets (all six scenes open):

| IDs | Source noun / clause / main predicate | Fixed scene members A, B, C; clause-match IDs |
| --- | --- | --- |
| `couriers-mixed`, `couriers-all` | `The couriers` / `who have blue bags` / `will get route cards.` | mixed: Courier A blue bag, B gold bag, C blue bag; matches A,C. all: all three blue bags; matches A,B,C. Reader context: prepare the route-card message. |
| `parcels-mixed`, `parcels-all` | `The parcels` / `which have star labels` / `will go on the cart.` | mixed: Parcel A plain label, B star label, C star label; matches B,C. all: all three star labels; matches A,B,C. Reader context: prepare the cart-loading message. |
| `books-mixed`, `books-all` | `The books` / `which have red covers` / `will go on the display.` | mixed: Book A red cover, B blue cover, C green cover; matches A. all: all three red covers; matches A,B,C. Reader context: prepare the display message. |

Each source record has stable ID/title/story, noun, clause, predicate, singular/plural labels, three members `{id,label,kind,feature}`, `targetFeature` and an explicit `matches` list. Predicates above are not parsed or inferred from prose; this is a finite authored meaning model. Tests independently verify each matches-list against the displayed member features and the table. The source is deeply frozen. Feature identity is always shown in native text and a shape/pattern as well as color: blue/gold bag labels, star versus plain labels, red/blue/green cover labels. Colors alone never decide an inaccessible task.

Three message forms per scene, exactly18 messages:

1. **Identifying detail:** `{noun} {clause} {predicate}`. The main statement refers to the scene’s matches-list. Explain: **“The detail identifies which {couriers/parcels/books} the message talks about: {matching labels}. It says they {action with will}. It does not say that the others will not {action}.”** Produce natural family-specific wording from the packet below, not a naive strip parser.
2. **Extra detail:** `{noun}, {clause}, {predicate}`. The noun group is already established by the scene: all three. The main statement refers to all A/B/C and adds the clause’s property about that whole group. Mixed scenes: the detail conflicts with the pictured exceptions; name them. All-share scenes: it fits all three. Never label this form ungrammatical merely because its extra claim is false. No claim that “commas always mean everyone” outside this fixed, established plural-group context.
3. **No detail:** `{noun} {predicate}`. Main statement refers to all three; it says nothing about their bag/label/cover. Removing an identifying detail can broaden reference; removing extra detail keeps the already established group but removes information. “The sentence still works” is not a test that meaning stayed the same.

Family-specific action phrases for interpretation: couriers **“will get route cards”**, other-inference **“get route cards”**; parcels **“will go on the cart”**, other-inference **“go on the cart”**; books **“will go on the display”**, other-inference **“go on the display.”** Do not duplicate “will” or lose agreement. Joined label lists are A and C, B and C, or A/B/C with ordinary English conjunctions, always full figure labels in narration. Avoid “only these get cards”; “only these are explicitly included in this main statement” is a scope distinction, not an assertion that others cannot receive cards.

For an all-share scene, explicitly say: **“Both versions include all three here. One identifies the group by its feature; the other adds that information about the group already identified.”** Both forms can be grammatical and fit; do not force a stylistic winner. The no-comma use of which is grammatical; some US style guides prefer that for identifying things. The game does not grade that style preference. This increment offers who/which as prepared words, not a pronoun-choice quiz. Whose/whom/where/when/why, object-relative omission, coordinated relatives, ambiguous real-world contexts and free-text parsing remain missing.

### Teaching, contrast, practice, application and return

Five separate, manually stepped teaching cards use **lanterns with silver handles**, never the practice couriers/parcels/books. Model Lantern A has a silver handle, B a wooden handle, C a silver handle; main sentence **“The lanterns will hang by the door.”** Detail fragment **“which have silver handles”** (no terminal punctuation; the complete sentence ends after its main predicate). These are separate source objects, not a temporary mutation of a practice scene.

- **T1 Main sentence and basic punctuation.** “The lanterns will hang by the door.” Names the lanterns and says something about them; starts with a capital and ends with a period. Separate sentences “The lanterns hang by the door.” / “They light the entrance.” can join with and. List example “The shelf holds a map, a pencil, and a bell.” Its commas separate list items; the later pair has another job. This is support, not a complete clause/list course.
- **T2 A detail about a noun.** Build “The lanterns which have silver handles will hang by the door.” Label the noun group and the relative clause. “Which have silver handles” depends on a noun here; it is not this activity’s complete main sentence. In our model it identifies A and C. Who is used for our pictured people; which for our pictured objects. Do not teach that these are the only possible relative words.
- **T3 Take the identifying detail out.** “The lanterns will hang by the door.” Now the message talks about all three. It is still a sentence, but the group changed. The earlier message did not say that B would never hang by the door.
- **T4 Add the paired commas.** “The lanterns, which have silver handles, will hang by the door.” Main statement talks about the established group of all three and adds a property about all three. B’s wooden handle conflicts with that extra information. The sentence is grammatical; its detail does not fit this fixed scene. Show both commas together, not a pause-only rule. In grammar these are defining/identifying versus non-defining/extra-information relative clauses.
- **T5 A separate all-share contrast.** Show another explicitly different example scene in which all three lantern handles are silver. Both comma forms can fit and include all three; the clause has a different job. Removing the extra detail keeps that group but loses the handle information. Return to the exact waiting practice message. Source pictures stay fixed within each example step; T5’s new scene is clearly named.

Open practice: **P1** construct a message from the three strips; **P2** move both commas together or remove/restore the detail; **P3** mark the figures the main statement explicitly includes; **P4** check marks or reveal the model and revise freely; **P5** switch to an all-share scene, a new noun family, or404’s attachment mode and return to the exact waiting trial. Hint: **“Read the noun group first. Is the detail identifying which ones, or adding information about an already identified group?”** Separate teaching is always available. Optional talk prompt: **“Say or write a new message for someone with you. Ask which people or things they thought it included.”** No text field, capture, automatic sharing or judgement of that original example.
