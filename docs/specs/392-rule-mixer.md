## Model and six original jobs

Each source has two original equations `a*x+b*y=c`. Coefficients a,b integers -6..6, c integer -24..24; each row requires at least one nonzero variable coefficient. Different rows may coincide or conflict. They are abstract number rules, not physical quantities or negative parcel masses.

| id | A (a,b,c) | B (a,b,c) | Teaching contrast |
| --- | --- | --- | --- |
| sum | (1,1,7) | (1,-1,1) | Add opposites; pair(4,3) |
| difference | (2,1,9) | (1,1,5) | Subtract matching y; pair(4,1) |
| scale | (1,2,8) | (3,-1,3) | Scale every term; pair(2,3) |

Any job is selectable with a neutral case title (no title states its outcome). Default new work scales A/B by1, operation add, no proposed pair and no requested preview/check/reference/teaching. These are instrument starts, not responses. Available scale factors integers -3..3 INCLUDING0; subtraction is scaledA minus scaledB. The result row is `u*A + sign*v*B`, all THREE coefficients processed. Display all signed products and each column sum; explicit positive magnitude products accompany products whose TWO operands are nonzero and whose absolute values are1..12. Zero scaling is allowed as an investigation of information loss, never described as a reversible equation step. Neither chosen factor nor operation is auto-snapped to a cancellation.

Preview can result in a two-variable row, one-variable row, `0=0` or `0=nonzero`. All are valid learner choices, including unhelpful ones. A combined row is a CONSEQUENCE of the original pair. It is not by itself equivalent to the system. Originals remain visible and unchanged. If either factor0, say that row contributed no information; both0 gives a tautology and proves nothing about the originals. A tautology from two zero factors proves nothing about the originals. A tautology from two NONZERO factors shows all three columns are proportional, so the originals describe the same whole line; a line is not every pair in the plane. Exactly one zero factor cannot produce a zero-variable row because the surviving original has a nonzero variable coefficient; no contradiction is inferred from a finite trial list. A nonzero constant with zero variable coefficients does prove the originals cannot both hold. No automatic success score or rejected mixture.

Reference classification uses the full originals: determinant D=aA*bB-aB*bA. D!=0 gives x=(cA*bB-cB*bA)/D, y=(aA*cB-aB*cA)/D. D=0 and BOTH aA*cB-aB*cA==0 and bA*cB-bB*cA==0 gives coincident whole line; otherwise none. Neither row is a zero-variable row under source rules, so that classification is valid. Never divide by0. Compute with exact rational helpers, not floating-point equality.

Reference chooses a deterministic elimination. Compute D from the full originals.
