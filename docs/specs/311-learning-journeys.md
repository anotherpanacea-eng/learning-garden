## Exact teaching content

The same twelve:
1. Make equal groups. Show an original picture of3rows×4tiles and say “Three plates, four bites on each. Twelve bites altogether.” Name plates, bites each and total. Invite `#cafe/groups`, choosing Little table through its own control. Ask “Which quantity is the question asking for?” Examples/counters remain support.
2. Ask a different question about twelve. Explain12÷3=4bites each versus12÷4=3plates; quantities and units make the questions different. Invite `#post/groups`. Suggest using the existing Carry action from Café and choosing another unknown if useful. Existing destination work always wins; carrying a model/support never transfers success.
3. Cover the ground, then walk its edge. Show original2×6 and3×4 tile rectangles. Both cover12square units; exposed boundaries are16 and14length units. Shared edges are inside, not fence. Invite `#workshop/same-ground`, choose Twelve tiles, build/keep/compare using normal controls. State explicitly that this board and kept picture last only during this visit and are cleared by leaving/reload.
4. Turn a plan and explain it. Invite the same board’s Turn case:3×4 and4×3 preserve area and boundary. Ask for an optional paper planting plan with12squares and labelled boundary; explain to someone why equal area need not mean equal fence. Paper is the kept artifact here; do not claim Notes saved the board. This return can happen in another sitting with a fresh board.

What changes, what starts?:
1. Separate rate and start. Original table x=0,1,2 / y=3,5,7 and simple labelled line for y=2x+3, x distance(km), y cost(coins). Rate2coins/km is different from starting cost3coins. Invite `#desk/linear`, Bag card through owning controls.
2. Compare what changes. Journey2x and Bag2x+3 have equal rates/different starts. Express3x+2 versus Bag2x+3: Express is cheaper at0km, tied at1km, dearer at2km. A steeper line is not always a higher total. Invite `#desk/linear`; user selects cards. Do not silently replace an existing card or answer.
3. Watch a quantity fall. Invite `#learn/math/zero`, the existing y=6−2x declining reference-height lesson; negative rate is already taught, not wholly missing. At0/1/2/3/4seconds height6/4/2/0/−2; the rate is−2height units/second. Reference zero is not “nothing exists.” Offer optional `#learn/math/halves`, y=(1/2)x+1, to contrast fractional increase. Explicit lesson link is a preview; its own Start controls own selection, preserve waiting work.
4. Decide where two plans meet. Invite `#learn/math/plans`: A=3+(3/2)x, B=7+(1/2)x, meet at4km/9coins within the existing0–6km domain. Ask for a kept explanation in the board and optional human discussion: what changed, what started, what units/domain make sense? Offer `#learn/math/views` as optional later return with a new context; keep supported and independent work distinct. Existing first/latest versions retain their normal meaning.

Text may be line-broken for legibility without changing quantities. Hearing uses existing explicit hearButton/bindSpeech, no automatic audio or new recording.
