## Construction and mathematical rules

Native “Squares in each row” select offers integers1…12. It can change only when no rows are placed; otherwise give an adjacent “Return the tiles first to change how many squares are in each row” explanation, with “Return all tiles” always available. Start each case at its suggested width but zero rows. Native “Lay one row”, “Lift last row” and “Return all tiles” buttons move whole rows between tray and plot. Lay is enabled only when enough tiles remain and rows<12; lift when rows>0. Return preserves the chosen width but clears rows. Widths not dividing stock remain useful partial exploration: show the leftover stock, never drop it or invent a partial row. There are no gaps, overlaps, individual-cell drags, hidden resizes or clipping.

For legal width w and rows h, placed=w×h, tray=N−placed. Area is placed square units. For h>0 perimeter=2w+2h length units; an empty plot has area0 and perimeter0, with no walk. Walk must enumerate exposed unit segments, not border tiles or all edges of all squares. Sequence from upper left: top left→right w; right top→bottom h; bottom right→left w; left bottom→top h. Exactly2w+2h different unit segments, returning to the start. Internal shared tile edges are not counted.

“Walk one edge” lights the next segment and increments a visible “Walked k of P length units” counter, capped at P. Final step says “Back at the start”. “Start walk again” sets k=0. No auto-walk/timer; the child sets pace. “Show outside edges” explicitly reveals all exposed segments as supplied help, without advancing k; “Hide outside edges” restores only the walked segments. Each construction edit resets k and reveal; no stale perimeter highlights.
