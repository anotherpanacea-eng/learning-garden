Pure work `{caseId,history:[g,...]}` starts with empty history. Derive current n,d by dividing the immutable original counts by each valid factor in order. Every factor is an integer≥2, divides both current counts exactly and strictly reduces positive d. Reject malformed/unknown case, impossible history, fractional factor, factor>d, nondivisor and no-op; do not clamp or mutate. There are naturally few valid steps; no arbitrary list cap. `groupPiecesCases`, case lookup, create, model, preview, apply, undo, compare and example are the new module's explicit interfaces (exact symbol spellings may follow existing naming). New temporary validation is against this finite content; historical notebook data is never validated against it.

For candidate integer g in2..d, preview whole groups `floor(d/g)` with `d%g` old pieces left, colored groups `floor(n/g)` with `n%g` old colored pieces left. Fits iff both remainders arezero. Only then derive new fraction `(n/g)/(d/g)`. Preview never changes work, never rounds a fraction and never proposes fractional piece counts. Choosing a nonfit is an exploration, not an error/attempt/penalty. This tool requires **complete equal groups**; a nonfit does not mean no equivalent fraction exists by another operation.

**Group size** native select offers every integer2..current d, starting with **Choose a group size** (`null`). Case selection is a native select, default first case. Retain per-case work and selected preview while changing cases and while switching modes. **Group these pieces** enabled only for a fitting preview; otherwise show why. Successful Apply replaces work, clears the preview to null, and leaves case selected. **Undo last grouping** removes one factor, clears preview and may be repeated to the original. There is no Reset button, automatic next case or automatic simplest-form choice. At d1 there are no offered group sizes; explain why, disable Apply and keep Undo available. No undo history is lost on preview, Compare or example.
