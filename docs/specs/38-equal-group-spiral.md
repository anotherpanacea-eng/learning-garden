# Same delivery, three questions

First curriculum spiral increment, 2026-10-20. Independent specification review cleared after resolving grouping-entry, shared-exposure and recovery wording findings. Extends the Café and Bramble through an optional serving/ribbon bench. Normal orders, stock, deliveries, rival rounds, table preferences and other destinations stay available and unchanged by this practice.

## Learning purpose

Keep one quantity triple fixed while changing what must be found: total objects, objects in each group (equal sharing), or number of groups (grouping). Name the units in every prompt and equation. The roles of the two factors matter even when the numerical product is unchanged. This is guided visual practice, not a placement assessment, a recall test or evidence of full division-topic coverage.

Six original cases, all freely selectable:

| Case | Groups | In each | Total |
| --- | --- | --- | --- |
| Little table | 3 | 4 | 12 |
| Another way to share | 4 | 3 | 12 |
| Picnic plates | 2 | 5 | 10 |
| Welcome-back supper | 5 | 6 | 30 |
| Long tables | 7 | 8 | 56 |
| Festival preparation | 12 | 12 | 144 |

The first two deliberately contrast the same total with different group roles. The other cases change scale, without claiming that all 144 multiplication facts receive new division lessons. Existing full-range fact and rival play remains intact.

## Experience

Entry links in Café and Willow Post Office open `#cafe/groups` or `#post/groups`. Each has a compact case chooser with six buttons, then one question/model page. The question page keeps a known-quantity ticket, the current question and editable model together; other case choices and adult explanations live behind a return link/details. Café uses pretend bites and plates; Bramble uses ribbons and bundles. No food is taken from the real cupboard.

A child may choose any of three unknowns directly. The displayed ticket and prompt omit the sought numeral. Switching unknowns preserves the exact arrangement and that question's draft. Every case/place keeps its own work, so changing cases, Back, route changes and reload do not discard a draft.

The model conserves the case's total objects between a tray and up to 12 groups, each holding up to 12. On first entry to a case/place, all objects begin in the tray. A total or per-group question begins with the given number of empty groups; a group-count question begins with **zero groups**, so the sought group count is not preallocated. The chooser can select the unknown before starting a case, and its case descriptions show only that question’s given quantities. Later unknown switches keep the existing arrangement as familiar practice. Allow adding/removing an empty group, moving one object in or out of a group, putting all objects back, and sharing one round among all groups. If group size is given, offer one whole-size scoop into a selected group as well. A shared round is atomic and disabled if insufficient tray objects or any group is full; it never partly changes the model. Large totals take at most twelve round moves, not 144 taps. Buttons work with touch and keyboard; dragging is unnecessary. Keep unequal arrangements visible and reversible. Never silently redistribute after a check.

The tray's numeric count and group-size/count counters are initially concealed. A child can count the pictured objects or request counters. The model is always explicitly visual practice. Record picture availability, model moves, counters, equation/explanation, narration and together-help separately; do not claim unaided performance merely because a help button was unused. An accessible description names the current arrangement and can expose counts: treat viewing the model conservatively as visual support for all attempts in this loop.

Checking the arrangement names equal-group constraints. It is support, not an answer attempt. The answer form accepts a whole number 0–144. Invalid text leaves the draft, with no recorded mathematical attempt. A numerical answer and the arrangement are checked separately: a correct number can fit even while the pictured groups need revision. Keep that distinction in feedback and record whether the arrangement fit at the time of the attempt. Retrying remains open; no penalty, lock or timer.

On request, an explanation overlay connects the same quantities to repeated addition, multiplication, and both division equations, with units and the current unknown named. A separate smaller example is available stepwise: two groups of three, using one group then both then the equations. These are support; opening a worked example never solves the live task. An optional “What changed? What stayed the same?” prompt invites conversation without scoring or storing prose.

## Crossing to Bramble or returning to the café

A visible invitation carries the selected case, its known quantities and **a cloned arrangement**, not a score, answer input, inventory action or mastery state. At the destination choose another unknown (default the next of total → each → groups → total) and begin its own answer draft. The source draft/arrangement stays exactly where it was.

Keep provenance on the first crossing: source place, source unknown, quantities, model snapshot and support flags. Mark the destination as having familiar quantities and preserve prior support separately from its own help/attempts. Every attempt is visual practice; no imported correct answer can produce an independent-success or recall label. Support/exposure from any earlier work on the same case remains part of its familiarity context. If that case already has work at the destination, reopen it without overwriting it; plainly say the earlier destination arrangement is waiting. A later page render cannot repeatedly copy a model or add an attempt.

This bench is separate from the original order and adaptive rival round, so a waiting guest, plate, pending packing question and Bramble challenge all survive. Leaving the bench returns to the original destination. No serving reward, inventory spending, café supper progress or Bramble gate completion is caused by this loop. Do not trigger an ending film merely by visiting the bench.
