## Mapping policy

Reuse actual authored `areas` question topic IDs and existing scoped `learningPlaces` declarations, with source paths/routes and their limits. Count a reference only at its stated scope. A direct question reference is not full-topic assessment; a supplied explanation is not an independently completed investigation. Do not treat the existing 87-node map’s background prerequisites as taught skills. New Living Garden/Bramble/café references can be added only with explicit current activity scope, not guessed from a matching noun.

The whole eight-subject graph is a baseline, not all learning: geography, arts, music, French/other additional languages and other missing areas are clearly labelled original **planned extensions outside Marble v1**, without invented Marble IDs or prerequisite edges. Missing subject organization does not mean every related idea is absent: science/history already include some geography-, art- and music-adjacent topics. Jane provides useful quest/response/review patterns and existing lesson-pack code reuse; do not merge its learner state/mastery/locks or duplicate Marble nodes. Confirm local game inventory against live source. No personal child/family content appears in this authoring map.

Use roughly seven reusable patterns: search/inspect/compare, assemble/allocate/check, change/measure/explain, read/infer/support, compose/execute/revise, build/transform/relate, and create/perform/reflect. Different topics require different content, representations, response modes and evidence; reusing a shell does not make every subject a multiple-choice exercise. Record authored examples versus generated variations, concept/representation/procedure distinctions, support/familiarity/retry boundaries, and observed versus unobserved abilities. PSD conversations remain reflective, not a numeric empathy/resilience score.
