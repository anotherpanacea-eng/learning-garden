## Exact grammar and manual execution

Round fields: `block:[null|n|e|s|w, null|n|e|s|w]`, `count:null|2|3`, `run:null|{cursor:integer0..6}`, familiar boolean, support and checks. Initially both arrows/count/run are null. A complete program requires two definite arrows and a definite count. Repeat each ordered pair count times; expanded length is4 or6. Same-direction pairs are permitted and can be wrong/boundary-blocked. No text parser or arbitrary command list is an input.

Only **Begin / restart this plan** creates run `{cursor:0}` for a complete program. Blank/incomplete Begin refuses without mutation; page changes never choose arrows/count or start a run. Cursor counts **attempted expanded commands**, including a blocked command. At cursor0 the courier is at the source, no command attempted. Each **Fly one arrow** advances the cursor by exactly one if the run is still open. Derive its prefix using the current frozen source start/target and the expanded commands through that cursor, via the pure walker. Stop after the first blocked command or after the last command. Repeated Step then refuses atomically. Refused Step never consumes a hidden command or creates a run.

Current run stores only a cursor, not a second mutable path/result. Its derived mathematical view uses its own current source/program. A valid cursor cannot exceed the expanded length or lie beyond its first blocked command. This is a working-model invariant, not a regrading of kept snapshots. Source/program always stay coherent while a run exists: **changing** either arrow/count resets run to null, retaining prior kept checks; choosing the same value leaves run untouched. Explicit Restart resets current cursor0 only; it does not rewrite checks or support. Every revision remains available without losing the job/source. There is no automatic run or automatic check.

Trace display shows the whole pair inside its bracket, selected count, the current repetition/arrow and the travelled path. Before a run no active execution pointer. At ready/mid-run, label **Next: repetition r, arrow a** where `r=floor(cursor/2)+1`, `a=cursor%2+1`. At a blocked attempt, highlight the actual blocked command: `r=floor((cursor−1)/2)+1`, `a=(cursor−1)%2+1`, explicitly labelled **Blocked**. At full completion say **Finished**, with no invented next repetition. A last-arrow highlight may remain labelled finished. Visible labels and outlines supplement colour.

Keep **two arrow slots in the block**, **repeat count**, **proposed expanded moves**, **attempted commands** and **moves actually travelled** distinct. Expanded counts are supplied model information, not an independent multiplication answer. For incomplete programs proposed moves are not yet given as a completed plan; no physical distance is claimed. At a blocked attempt, attempts can exceed travelled moves by one. The optional full expansion does not itself execute the program or establish that a child independently predicted it.
