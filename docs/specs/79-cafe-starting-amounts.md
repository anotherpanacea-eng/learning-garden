# 79. Opt-in Café starting amounts

Implemented in a review branch; not a claim of merge or deployment.

The build contract is the bounded **First increment: Café starting amounts** in the [reviewed proposal](proposed/challenge-bands.md). It adds an explicit per-explorer Grown-up notes choice using the existing small/full pools. Local Café range buttons override it. Legacy choices, active guests, connected quantities and recorded evidence keep their existing meanings. Other starting controls remain deferred.

See the [implementation review](../reviews/79-cafe-starting-amounts-implementation-review.md) and [upstream audit](../source-audits/cafe-starting-amounts.md).
