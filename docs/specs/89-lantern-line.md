## The missing contrast and existing overlap

The lantern walk needs two stops along one whole route, from Gate0 to Arch1. Add an optional `#numbers/lanterns` visit: place two requested fraction markers on one common line, then compare the **actual placed markers**. Existing Fraction Trail already builds partitions, places/reads a flag, accepts equivalent fractions and compares kept/current ribbons. ## Three short open turns

**Place.** Intro: “The lantern walk runs from Gate0 to Arch1. Both lanterns use this same whole walk. Put each lantern at its requested fraction.” Show the source requests, one shared line and separate movement controls. Each marker starts absent, not at zero. **Start Amber at zero** (and Blue equivalent) explicitly places it at zero. **Back one part / Forward one part** moves that marker by one part of its own requested denominator. At index k, its horizontal coordinate is `12*k/denominator`; its requested position is `12*numerator/denominator`. No pixel tolerance, floating grading, drag or auto-correction. Bounds0..denominator refuse without mutation; keep focus on the enabled reverse control or current heading. Text names the denominator and current step count, so no unseen-recall claim is possible.

Both markers live on **one** shared horizontal zero-to-one axis. When endpoints coincide, use separate marker shapes above/below the axis with leader lines at the identical x coordinate; vertical offsets distinguish labels, never values. Equal-whole endpoints, interval lengths and labels stay aligned at every width. A native optional **Show Amber's equal parts / Show Blue's equal parts** control changes only guide marks on this same fixed axis; it cannot move either marker or change the scale. Default guides may be twelve light equal intervals, explicitly model guides rather than twelve required parts of either request. Supplied per-marker equal-part guides count as help. Text equivalents state each actual step count/denominator and whether its marker is absent.

Optional teaching explains: “A denominator names how many equal parts make one whole. Three equal parts are smaller than two equal parts of this same whole. One third is closer to0 than one half. A fraction with more parts is not always farther: compare the size of each part and how many are taken.” A separate original example shows1/2 and1/3 on a shared0–1 line, with three revealable steps: keep the whole fixed; mark equal halves/thirds; compare horizontal distance from0. This is supplied teaching. Source/help changes never revise a saved example. Narration is explicit/local and names the visible object; no hidden answer is used as a substitute for current instructions.

**Compare.** Retain source requests and the same actual-marker figure. Ask **“In the line you made, which lantern is farther from Gate0?”** Choices remain Amber / Same point / Blue in stable source order. They describe the learner's current diagram, not automatically the requested fractions. A choice is retained even if a marker is absent; checking then records order as unobserved. **Check this line** reports three separate outcomes: placement for each requested fraction, and whether the chosen order matches the actual two positions. Missing markers/choice are null, not failure. A wrong placement with an accurately read order is false/true, not wrong reading. Example feedback: “Amber is at1/2; Blue is at1/3 on this line. Amber is farther from0. Your order choice fits this line. Blue's requested stop was2/3; you can move it or keep this version.” Exact displayed feedback freezes in the check. Changes to markers, comparison choice or guide/support state make live feedback earlier; page navigation does not. No automatic advancement or correction. **Change the stops** returns without losing either marker or response.

**Kept.** One optional **Keep this version** stores the complete source, positions, comparison, support and applicable check. Incomplete work is welcome. A current revision never changes this copy. Explicit **Replace our kept version** confirms that it overwrites that one slot, with a notes-download suggestion; it must not promise to retain the old copy. Keep at most four recent readable checks per request, with a visible rolling-window explanation. Preserve malformed siblings and their order beside surviving records; no load-time trimming. Earlier checks and the kept copy show their own saved values and text. Open returns to Place/Compare and Number Garden remain available.
