## Play and teaching

Bramble lays out two aligned rows of ribbon knots. Choose or deal each starting length from1–7, who starts, and how Bramble plays. Default5 and3, child first, paying attention. The choice of first player can decide the game with best play; describe this on setup without giving away the plan. A turn takes a positive number from exactly one row. Whoever takes the last ribbon wins. A zero row stays pictured as an empty row; both zero is terminal, never a fresh setup.

Tap a row, then a count, then **Take these ribbons**. A visible draft says which row, how many taken, and how many would remain. Tapping another row clears the count; clear restores an unchosen draft. Drafts remain revisable without advancing a turn. After the child's move, **Let Bramble play** executes exactly one stored opponent move; no automatic replies, timers or animation. Show the last move as an equation and identify the next player. Finish with either player's win, allow another game, retain the old game unchanged and offer one optional round note. Leave/reload returns to the actual board, turn and draft, never a new deal or opponent roll.

The dial describes Bramble, not the child: sleepy picks uniformly among legal moves; paying attention takes an immediate win if possible, otherwise uniform legal play; has a plan makes the rows equal whenever possible, otherwise first legal move. Legal order is ascending row index then ascending take. Exact equality is the losing positive position: from unequal rows reducing the longer to the shorter leaves equality; from equal positive rows any move breaks equality and permits a matching reply. Zero-zero is terminal losing for a hypothetical next player. No guarantee that any starting player wins. Store actual opponent moves and never replay randomness. Validate/clamp random samples to finite [0,1) as in existing games.

Optional **Bramble explains** supplies four pictured steps: (3,3) child turn; child takes2 from row1 leaving(1,3); Bramble matches2 from row2 leaving(1,1); child takes the final1 in one row, Bramble takes the final1 in the other. Copy explains that the player handed equal positive rows cannot force a win against matching replies. The waiting game is unchanged except supplied-help tags. Back/Next reveal one thought at a time. **Try this example** opens an in-memory practice board at5,3 with child first and Bramble's plan, using the same manually stepped controls. Return restores the waiting game; leaving/reloading clears only temporary practice. No practice result is saved or treated as independent evidence. Seeing explanation marks `explanation`, and readable prior explanation marks later new games `explanation-before`; practice is visibly supplied-strategy play.
