## Geometry, provenance and drawing

Angles are chosen exact model values, never measured off the screen. Mathematical raw free vertices A=(0,0), B=(1,0), C=t(cos A,sin A), t=sin B/sin(A+B). Every allowed pair has nonzero sine denominator and a closed, counterclockwise, nondegenerate triangle. Interior sectors before rotation: at A start0 sweep A; at B start180−B sweep B; at C start180+A sweep C. Exterior chosen at C extends the B→C side past C: E=C+60u, where u is the unit direction B→C **after normalization into drawing units**, before global rotation. Its sector starts180−B and sweeps A+B to end180+A. This is the exterior adjacent to c, not a reflex angle or the whole outside of a shape. c+outside=180°; outside=a+b. Never label an outside angle with c or report its supplement as an interior angle.

Normalize raw vertices about their centroid with one positive scale so the furthest vertex is110 drawing units for Large,80 for Small. All sides use that same scale. Then rotate about the centroid by shared r and invert y to screen center(320,280), viewBox640×560. Changing size changes drawing lengths, not model angle values. The parallel line through C extends120 drawing units each way in the unrotated horizontal direction; base AB lies on its parallel horizontal line. Draw AB's line extended60 beyond each endpoint when the proof uses it. All those points are within230 drawing units of center at every rotation; exterior endpoint within170. Displayed line segments represent extendible straight lines. No scene claims a finite pair never meets just because it does not meet on screen.

Reason sectors at C subdivide the lower straight half-turn, counterclockwise from180+r to360+r: copied a starts180+r sweep A; existing c starts180+A+r sweep C; copied b starts360−B+r sweep B. This gives a,c,b in that order. a matches A by alternate interior angles along AC; b matches B along BC. Draw parallel chevrons on base and through-C line, only when the through-C line is present. Thin sectors remain exact, not widened for readability. Wedges highlight corners, not a claim that all angles are equal. Printed a/b/c tags and leaders distinguish them without colour; ordinary HTML names both vertices and each relation. Every original interior angle of exactly90° uses a right-angle square (always B in panel mode); copied and gathered corners always use arcs. No decorative equal-arc marks that conflate a/b/c.
