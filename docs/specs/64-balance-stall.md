## Complete finite first pack

Use identical practice unit weights, each **one model mass unit**, and a whole sealed parcel whose fixed model mass includes its wrapping. Model units are not grams, coins, object counts or the mass of only the parcel contents. An equal-arm schematic with matched pans compares their total model masses; the app supplies results, not physical measurements. Positions of the labelled tokens do not affect model mass. A higher pan has less mass; the heavier pan is lower. Level means the same mass. Text repeats that relationship without relying on colour, motion or position alone.

## The actions and mathematical contrasts

Native buttons provide **Add one unit to left/right/both** and **Remove one unit from left/right/both**. Add into the last group; remove from the last nonempty group, then the first. No parcel itself can be added, removed, opened or split. Removal from an empty pan and paired removal when either pan lacks a loose unit are disabled/nonmutating. Additions respect each pan's20-loose-unit limit; paired actions are atomic and fail without changing either pan if either side cannot act. No abstract subtraction of an absent/negative weight.

Change the balance one explicit step per tap; no autonomous animation. Text and schematic show equal / left heavier / right heavier from the source's actual parcel mass and live loose counts. A guessed parcel mass **never** drives the apparatus or its feedback. Same additions/removals preserve an existing equality; they also preserve an existing nonzero difference and **do not repair an already unequal balance**. One-sided actions are allowed experiments, not mistakes that block access. Undo by adding back/removing a compensating unit on that side, or return to the case's starting arrangement. Reset is explicit, keeps earlier recorded checks, clears current proposed answer and move/support trail only as stated below; it does not create a visit or erase historical work.

A compact current-action note explains the real result. Example from parcel+2=7: “One unit came off each side. Both totals dropped by one; the balance is still level.” After two removals parcel=5. If left alone loses one, say “Only the left changed. The right is now heavier.” If both are then removed, say “Both changed by the same amount. The right is still heavier; that did not repair the earlier difference.” Do not teach that a particular button sequence is the only valid solution. Model text is supplied mathematical support, not an independently composed explanation.

A separate **My idea for the whole parcel** native selector permits blank or1–12 model units, and “Check/keep this idea” records it with the current apparatus. A correct proposed value can be recorded without performing paired removals or isolating the parcel. These are separate observations: proposed value matches the supplied model / parcel currently isolated on a level balance / paired removal tried while level. Do not collapse them into a solved/mastered flag. An empty idea stays unobserved and can still be kept; support/retries/returning remain open. Known cases offer “Keep this balance” without an unknown-value question.
