# 87 · Seed Stall chance experiment

**Status:** Proposed for independent specification review. No runtime, atlas row, or release is authorized by this document.

## Problem and smallest useful experiment

The Number Garden has tables and bars of supplied model results, but no activity in which a learner configures a chance source, predicts, makes repeated draws, and compares the outcomes. Add one optional **Seed Stall** experiment at `#numbers/seeds`. It belongs to M6, Data, statistics and chance; choosing a model, explaining a prediction, and revising an idea also exercise M7 mathematical practices. The route is always open. It does not inherit the multiplication check-in, create a level, certify probability knowledge, or unlock anything.

The bag has six same-sized pictured seed counters. Each has either a **sun** or **moon** mark, also distinguished by color. The learner chooses the number of sun seeds from **0 through 6**; moon seeds fill the other slots. Every draw in this **screen model** selects one of the six visible positions with equal chance, shows its mark, returns it, and mixes by selecting afresh from all six positions next time. The bag is unchanged by a draw. This is a virtual random model, not an observed physical draw or evidence that a real bag mixes fairly. No hidden source or authored result sequence is presented as random.

One investigation freezes a configured bag and allows up to **three short runs of six draws**, one draw button press at a time. Each run has its own optional prediction made before its first draw. A textual tally and two fixed-baseline bars show the actual six outcomes, including zero. Completed run summaries remain beside the same frozen bag for comparison. The learner can start another investigation with a changed bag. There is no without-replacement mode in this increment: that contrast needs separate source and interaction review. A short run can depart from the more-likely outcome; it cannot prove or disprove that the screen selector or a real bag is fair.

## Exact learner flow and copy

The Number Garden hub offers **Try the Seed Stall** without changing another task. A direct visit opens the same route. Opening it or editing the unsaved chooser allocates no progress root. The chooser defaults to three sun and three moon seeds on a fresh visit; the count is an editable local draft, not a saved prediction. Native controls change only that count. The six marks and the line **“Your bag has 3 sun seeds and 3 moon seeds.”** update together. The model rule is visible before Start: **“This is a screen draw. Each of the six pictured seeds has the same chance each time. We return the seed before the next draw.”** The learner can inspect all seven bag arrangements, including a one-mark-only bag, without starting an investigation. This visible chooser supplies possible bags but does not claim a saved experiment or a completed chance lesson.

**Start with this bag** creates an investigation with its own frozen source. It opens run 1 with no draws and the prompt **“In six draws, what do you think might appear more often?”** Choices: **“More sun marks”**, **“More moon marks”**, **“The same number”**, **“Not sure yet”**, and **“No prediction”**. The last choice clears the prediction; leaving it unset also permits drawing. Show a short explanation beside the source, derived only from its pictured composition:

| Sun : moon in the frozen bag | Exact source explanation |
| --- | --- |
| 0 : 6 | “Only moon marks are in this bag. Every screen draw will show moon.” |
| 1 : 5 or 2 : 4 | “Moon is more likely on each draw. Six draws need not match a guess about their final counts.” |
| 3 : 3 | “Both marks have the same chance on each draw. Six draws need not end in a tie.” |
| 4 : 2 or 5 : 1 | “Sun is more likely on each draw. Six draws need not match a guess about their final counts.” |
| 6 : 0 | “Only sun marks are in this bag. Every screen draw will show sun.” |

The prediction can change until the first draw, then stays as recorded for that run. The activity never marks a prediction correct or incorrect. **Draw one seed** triggers exactly one new selection. Show the selected seed and **“Returned to the bag. All six seeds can be drawn next.”** The source bag remains in view. After each draw, the run shows its ordered marks, sun/moon counts, and bars on a common 0–6 scale. A missing draw is blank, not a moon result or zero count. The draw button says **“Draw seed 4 of 6”** when appropriate; it cannot make a seventh draw. The run can be left and resumed, including a run with zero draws.

After six draws, show **“This run showed X sun and Y moon. Your prediction was [frozen choice / none].”** Then show: **“A bag with more of one mark makes that mark more likely on each draw. One short run can look different. These counts do not test a real bag or prove fairness.”** For a one-mark-only bag, replace the first sentence with **“This bag can show only [mark], because every pictured seed has that mark.”** This is a factual source distinction, not a grade. The result never says a wrong prediction caused an error or that the next draw is “due” to compensate. **Try another six draws with this bag** starts run 2 or 3 with the same frozen source and a fresh unset prediction. Completed run counts appear together in a small labeled comparison table; no averaging, percentage, convergence curve, or formal theoretical-frequency calculation is asserted. After run 3, that button is absent. **Change the bag for a new experiment** opens a chooser seeded from the current count; it leaves the prior investigation intact until explicit Start. The learner may also resume any readable earlier investigation from the compact history. Starting another investigation when the readable cap is full announces which oldest readable investigation will leave the in-app history; the notes download should be offered before that action.

One optional **Talk together** disclosure asks, “Which mark was more likely from the bag? Did every short run have to follow that pattern?” Its answer explains that returning a seed leaves the next draw's chances unchanged. It does not quiz or store a spoken response. All newly visible prose uses American spelling and no em dash.

Results use ordered marks, a compact tally/table and two bars sharing a zero-to-six baseline with each numeric value exposed in text. The 0-sun/6-moon and 6-sun/0-moon settings remain legible. Use one clear stage at a time, with history and Talk together in native disclosures.
