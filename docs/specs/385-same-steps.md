## Missing action and encounter

213/218/223/312 already connect affine rules, tables and graphs.367 handles fitting a line to observations;383 tests one pair in two affine rules. None lets a learner construct changes across several intervals and contrast constant with changing rate. Existing Equality Desk bracket work is symbolic single-bracket transformation, not this operation. This slice adds that action inside the existing Equality Desk, at exact `#learn/math/equality`, as an optional **Same steps?** mode. No new town destination, prerequisite test, story gate or assessment owner.

The learner selects two intervals between adjacent rows of a supplied table. For each interval, +1/−1 controls build an across change and an up/down change from its starting point. The proposed step is drawn beside the fixed actual points. A wrong or unfinished construction remains visible and keepable. Explicit **Compare steps** shows the actual differences, the proposed differences, their per-one-input rates when defined, and the source explanation. A same-rate but different-vector step is distinguished from reaching the next row. Optional **A separate example** uses other numbers. A literal current idea (`same`, `different`, `not-sure`, or none) is not graded.

Six open cases are specified in the companion: steady rise, steady fall, flat, square, doubling and a linear table with a skipped input row. A given table/rule/source is never regenerated on render. New cases use integer rows and the same axes, x 0..4 by 1; y −4..16 by 2. Grid squares are not units. Plot only the actual dots, actual selected-step references when elected, and the learner's constructed steps. Do not join dots or imply linear interpolation of a curve. Printed coordinates and signed differences provide the complete nonvisual equivalent.

Spec 49 §5: teach input/output change using a separate worked step; contrast equal x steps with different y changes, plus the skipped-row trap; supported practice constructs arrows with optional reference; new use tries another rule or skipped row; return reopens/copies a named kept step beside the existing affine work. This teaches selected M4-V rate/graph relationships. It does not teach full quadratic/exponential courses, prove an unknown function from finite samples, complete the prerequisite graph or assess independent proficiency.

## Exact mathematics and child actions

An interval i goes from own-source row i to i+1. Actual dx=end.x−start.x and dy=end.y−start.y. All source x values are distinct, so dx is nonzero even in an imported reordered table. The actual rate is exact reduced dy/dx, using existing Equality Desk rational helpers. For a proposed step, rate is undefined when proposed dx=0: show the companion explanation, never NaN, infinity or0/0. A fit means BOTH proposed differences equal actual differences. Rate equality alone is insufficient to reach the next row. Compare selected actual rates by exact cross-products/rational equality, not rendered rounding. Classify a proposed step in this order: both changes match → reaches the next row; otherwise proposed dx is nonzero AND rates equal → same rate, different vector; otherwise → other mismatch. A proposed dx=0 never counts as same rate, including(0,0); show the zero-across note.

Each interval owns one proposed vector; selecting it in both slots shows the same vector twice and the explicit same-interval note. No different-interval requirement or forced correction. Changing selections preserves earlier vectors for that source. Absent vector means not built; controls start it at(0,0) then apply the requested unit change. Each component is an integer −200..200. End controls disable at bounds. A constructed endpoint outside the frozen axes remains kept, with its exact coordinates and an outside-window note; clip the drawn segment, not the data. Do not silently clamp an imported or proposed value. Printed arrows name signed changes. Horizontal and vertical legs stay separately labeled A/B and across/up/down; color alone never identifies them.

The reference shows selected actual/candidate values and the source's literal explanation only after Compare; `referenceShown` stays true for that working version after further edits. The optional example sets `exampleShown` before displaying it. No outcome, correct flag, attempt counter, mastery or inferred familiarity is stored. The current idea stays literal when intervals change and can be revised; its heading names the currently selected A/B interval row numbers, and says it concerns those two intervals. Supplied rows/rules are always available, so there is no claim of answering without exposure.
