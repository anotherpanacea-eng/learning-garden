# 213 — The Courier’s Price: slope to a linear equation

Bounded proposed Keeper’s Desk teaching bench. No learner-specific names, grades or school material. This slice connects a familiar steady rate/slope to a fixed starting amount and a rule, then uses the rule backwards. It does not teach the full linear-equations unit, signed/rational slopes, arbitrary graphs, systems, formal proof, or equation parsing.

## Learning and story purpose

Pip is comparing invented delivery price cards for the next town gathering. A charge to prepare the bag stays fixed; each kilometer adds a constant amount. The learner can vary distance and see a bag/route picture, table and coordinate graph together, name the two parts of the equation `y = mx + b`, then find a distance for a stated total. The bench is freely available at `#desk/linear` regardless of act or other Desk work. No character/reveal contradicts spec 120. The gathering itself is not implemented or completed here.

At zero distance the model still has its bag charge: mathematical starting value, not a claim about actual transport pricing. Units: x = distance in kilometers, y = total in pretend coins, m = coins per kilometer, b = coins. This is price versus distance, not distance versus time or flight speed.

The explicit contrasts are rate versus total, slope versus intercept, a line with a fixed start versus a proportional line through the origin, and a rule valid for the stated model versus solving for one input. A table/graph picture alone is not independent evidence. All responses are supported practice within the shown model; no frontier, mastery, age, speed or independent-recall update.

## Teaching and turns

Entry: what this model is for; Start card. Four explicit pages, one primary question/action per turn, with Back/Next/step navigation and a compact source card retained on every page. No mouse-only gesture; touch/keyboard buttons and number fields suffice.

1. **Try the price.** Distance 0–6 with decrement/increment buttons and labeled number input. Stepping changes the paired picture/table highlight and point on graph; domain/axis ticks stay fixed. Show `bag charge + distance × rate = total` with units. Start at zero. Teach “each extra 1 kilometer adds m coins; the bag charge does not repeat.” At least two labeled points illustrate rise over a one-kilometer run. Provide a concrete per-one group explanation before slope terminology. No negative or fraction prerequisite.
2. **Name the rule.** Keep the pictured source and table available. Label x, y, m and b explicitly, with persistent `y = m × x + b`. Two independently editable whole-number fields for m and b; Check rule. Distinguish swapped rate/start, total mistaken for rate, and a correct pair using the frozen card. Empty/malformed inputs show an input message, not a wrong attempt. After a check, fields stay editable. Optional Show me how explains the source equation and substitution; always available, never a cost.
3. **Use it backwards.** For the frozen target total, type distance x. Check by substitution; show how subtracting the one-time charge leaves the distance-dependent part, then dividing by rate gives distance. Help may explicitly give the worked solution and is retained as support. No forced restart on an error. A correct result is “this distance fits this card,” not “you mastered equations.”
4. **Compare and keep.** Compare card 1 and card 2’s same m/different b using a small common table and labeled lines/static values. Contrast x=0, fixed difference and proportionality. Explicitly label this as another shown teaching example, not an unseen check. Optional free explanation (up to 800 characters) and Keep this page; free prose is never machine graded. Can keep with a blank or typed note; revising and keeping again updates only this card’s kept snapshot and preserves its first kept version. No story/film ending or all-cards gate. Return link to Desk case and two-way Post Office link; waiting deliveries/Desk case intact.

Common graph 0≤x≤6, 0≤y≤20, discrete distance input with a line segment labeled “model between the pictured points.” Continuous linear interpolation is part of the stated invented price model; response tasks use whole distances. SVG labels, axes and text table support the graph. The current point and one-step change are indicated without relying on color. No axis rescale, dragging or animation required.
