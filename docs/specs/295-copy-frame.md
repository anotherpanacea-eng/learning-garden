## Actions, shape and exact quantities

Four stable native buttons: Width −1 / Width +1 / Height −1 / Height +1. Each changes exactly one length by one length unit when it stays within1…12. Opposing side changes together so the copy always remains a rectangle. No snapping to a goal, clipped overshoot, stretch of unit size, hidden correction or negative/zero side. Disabled boundary controls link to the visible board-limit explanation. At the upper or lower bound only the unavailable direction is disabled.

Turn copy swaps current width and height and lines its corner up again. This is a quarter-turn followed by repositioning, not a claim of rotating about the displayed shared corner or a coordinate-transformation lesson. Area stays unchanged. Turning a square is allowed and leaves the displayed dimensions unchanged; it still closes the optional comparison as an explicit material action. Reset copy restores that case's original dimensions, hides its comparison and retains its area-square choice. It does not reset other cases or the explorer's notebook. Material changes always hide the supplied comparison until requested again.

Show area squares toggles equal unit squares inside the copy, each1 × 1 original length unit; there are exactly width×height cells without overlap or missing space. It is a view choice and leaves the optional comparison open. Hide area squares reverses it. Turning retains that choice and rebuilds cells for the new orientation. No original-sized fractional cards are manufactured. The original outline stays fixed regardless of copy edits.

Compare measures explicitly opens a supplied table and interpretation of current dimensions, never a submitted response or an independent explanation. Original area=a×b; copy area=w×h. Direct matched-side factors are w/a and h/b. A direct scaled copy requires w×b=h×a. A turned scaled copy requires h×b=w×a, matching original width a with current height h (factor h/a) and original height b with current width w (factor w/b). Prefer direct correspondence when both hold (squares), otherwise use turned correspondence if it holds. If neither holds, describe a different rectangle shape and show direct width/height factors. Never label3 × 2 a distorted version of2 × 3 merely because the display widths differ.

In a turned match, explicitly label which sides are paired in the table and explain that Turn copy can line the corresponding directions up. Both arrangements count as the same shape. For all rectangles, checking the two dimensions suffices here because opposite sides are equal and all corners are right angles. This is not the criterion for arbitrary quadrilaterals. No angle gets multiplied by the length factor.

The common factor k is current/original in the selected correspondence, never reversed. The area factor is (w×h)/(a×b), exactly k×k for a same-shape pair. Use reduced rational values, integer text if denominator1 and `n/d` otherwise; factors are unitless, original/copy dimensions carry length units, areas carry square units. Supply singular at1. There is no zero quotient. Table rows identify both matched side pairs and both areas with units. Never infer area factor from one side if the shapes differ; report their actual area ratio and say it does not establish similarity. A larger area can still have another shape. Same-size matches say same shape and size; factors below1 mean smaller, above1 larger. A turned factor1 match has same shape and size despite different displayed width/height.

Only inside an explicitly opened comparison, and only when similarity holds and k equals that case's requested factor, show the factual line: These matching sides have the requested factor [k]. You can keep exploring. It is supplied construction interpretation, not achievement evidence. There is no automatic requested-match line before Compare, including direct or turned requested copies. An edit closes the comparison and its interpretation. A different same-shape factor remains a useful scaled copy; Compare says the invitation asks for another factor. Distorted/partial constructions remain editable and are discoveries, never wrong-answer penalties.

Adding the same positive amount to both dimensions of a nonsquare rectangle does not preserve its aspect ratio. Adding equally to both dimensions of a square does preserve its shape, and also has one common multiplicative factor. The square comparison supplies this exception rather than claiming addition always distorts. No operational-history claim is made: the board knows the dimensions, not how a child reasoned.
