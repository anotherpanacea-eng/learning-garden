## Source and pure model

New `dist/sentence-details-content.mjs` exports `detailCopy`, `detailTeaching`, `detailModel`, `detailScenes` (id/title index) and detached `detailScene(id)` factory (null for unknown id). Runtime factory/copy equals the independently reviewed finite JSON, checked once before qualification rather than a permanent prose-sync gate. Original simple SVG schematics are rendered by the UI, with no remote art/font/API dependency. Captioned features are authoritative; icons must depict those features or stay decorative.

Each scene owns `{id,title,context,purpose,clause,entities:[left,right],base:Token[],trials:{[entityId]:{tokens,meaning,sceneNote,purposeNote}}}`. Each entity owns `{id,text,label,kind,feature:{icon,text}}`. Current kinds: parcel/crate/courier/gardener/kitten/bunny/basket/stool/lantern/boat/book/map. Feature icons: star/plain/stripes/empty/spoon/circle/triangle/moon/bridge. They are a small original illustrated vocabulary, never learner identifiers. Every caption remains visible, so no outcome depends on color or picture recognition alone.

Tokens are complete authored literal segments, `{text, noun?:entityId, detail?:true}`; preserve all leading spaces and punctuation. Each base has both noun tokens once and no detail. Each attached trial has both noun tokens once and exactly one detail token immediately after the chosen noun. Joining token.text yields the exact current sentence. The detail token text is exactly one leading space plus scene.clause; deleting that one detail token from a trial deep-equals base, noun token.text equals its entity.text, and trial keys equal entity ids in source order; but no runtime English parser or case-changing generator is used. Interpretation and scene/purpose notes are authored strings, not inferred or scored. Semantic correctness requires independent finite grammar review; token-shape checks alone cannot establish it.

New `dist/sentence-details-core.mjs` exports:
- `initialDetails()` → `{caseId:firstId,drafts:{}}`.
- `changeDetails(state,action,value)` → detached changed state or null for invalid/no-op.
- `detailsPresentation(state)` → `{scene,anchor:null|entityId,tokens,sentence,meaning,sceneNote,purposeNote,canUndo}` or null for invalid state.
- `detailsNarration(state,view)` → current task wording plus only the elected visible teaching/model parts.

Drafts are visit-only keyed by the6 known scene ids. An absent draft reads `{anchor:null,previous:null}` without materializing it on view. A draft is `{anchor:null|own entityId,previous:null|{anchor:null|own entityId}}`. Validate the entire model on every core call: state/drafts and each draft/previous must be plain own-field objects, current caseId and drafts must be own fields, draft keys must be among the6 known ids, and anchor/previous must be own. Inherited records, unknown draft keys, wrong-case entity ids, non-object/array drafts, invalid anchors or malformed previous objects return null, never throw. Unknown extra own TOP-LEVEL state fields may be cloned; they are not draft keys. No version envelope, migration, hash registry or serialized import is added. Valid unknown extra own state fields can be preserved by cloning; none drives rendering.

Actions: `scene` selects a different known scene but retains every draft/Undo; same scene no-op. `attach` selects one of the current scene’s entity ids; same attachment no-op. `remove` sets anchor null (no-op if already null). `undo` restores previous.anchor, then clears previous (no-op if none). Each attach/remove replaces previous with the prior current anchor; a second Undo is disabled. First attach may therefore undo to no detail. Undo affects only current scene. Trials use factory source and authored versions, never mutable source edits. `detailsPresentation` with no attachment uses base, copy.separateMeaning and empty scene/purpose notes. After normal route entry, no mode/scene/attachment/panel/Hear operation mutates app state, localStorage, Notes or a parent writing draft. Entry’s existing room-visit record is outside that baseline. Compare the whole localStorage map, including rooms, after entry. Tabs/redraws do not change the hash or call app-level render(). User-initiated global voice/speed preference changes remain their existing separate behavior.

View shape is separately ephemeral: `{teachingOpen:false,modelOpen:false,teachingPage:0,modelPage:0}`. All values wait across mode/case changes in this visit; clamp page indices to their source lengths. Opening/closing panels changes only view. No help/reading/attempt count is stored. Native teaching/model <details> bind guarded toggle listeners on the details element itself; write its open property to view, with an equality guard that ignores programmatic open restoration. Before mode/content redraw and before Hear, snapshot the connected current mode’s actual disclosure open states, covering queued toggle timing. Preserve joins Teaching/Talk disclosure states in a separate joinsUi object across mode changes. Narration clamps finite page indices to0..3, defaults non-finite indices to0, and treats flags other than strict true as closed. Source counts are fixed4; paging clamps and disables at ends, never wraps. No new view reducer/framework is needed.
