## Finite teaching and tasks

1. **Two arrows, one object.** Teach: consider only the horizontal forces on the same cart; right is positive, left negative. Opposite arrows cancel by magnitude. Net force = right force − left force, measured in newtons (N). Vertical forces balance; friction and air resistance are omitted in this toy. Interactive sliders 0, 2, 4, 6, 8 N for each arrow; text equivalents and SVG arrow lengths. Guided case: left 2 N, right 6 N → +4 N (right). Task: left 6 N, right 2 N, choose +8 N right / −4 N left / 0 N. Correct middle. Hint: subtract left from right. Different example: left 4, right 4 → 0 N. All checks cite the frozen task, not mutable playground values.
2. **Balanced can still move.** Teach: zero net force means no change in velocity; a cart already at rest stays at rest, one already moving right keeps the same speed and direction. Acceleration is change in velocity per second, not velocity itself. Guided: 4 N each way, initially +2 m/s → +2 m/s after one second. Task: 6 N each way, initially −2 m/s, choose stays at −2 m/s / stops at 0 / changes to +2. Correct first. Hint: ask whether there is a change, not whether there is motion. Different example: 2 N each way, initially 0 → remains 0. Diagram compares equally spaced positions for constant motion and unchanged position for rest.
3. **A fixed mass changes velocity.** Teach: constant mass 2 kg; acceleration = net force ÷ mass, units m/s², velocity after one second = starting velocity + acceleration × 1 s. Only straight-line, constant-force, one-second cases. Interactive previous force arrows with displayed signed acceleration; no animation or physical directions. Guided: +4 N / 2 kg = +2 m/s²; starting +1 m/s becomes +3 m/s after one second. Task: net −4 N, mass 2 kg, initially +3 m/s; choose −1 / +3 / +1 m/s after one second. Correct third (+3 + −2). Hint: a leftward acceleration reduces this positive velocity; it does not instantly turn velocity left. Different example: −2 N / 2 kg = −1 m/s², initially 0 becomes −1 m/s after one second.
4. **Read collision evidence carefully.** Invented supplied trials, same 2 kg cart, +2 m/s before contact, 0 afterward, same target/measurement method: rigid pad A shape change 0 cm, stopping time 0.10 s, cost 1 token, depth 1 cm; foam B shape change 3 cm, 0.40 s, cost 3, depth 4; spring C shape change 2 cm, 0.20 s, cost 2, depth 3. Shape change is observed deformation, not a force measurement. For the same mass and velocity change, longer stopping time corresponds to smaller magnitude of average net stopping force (2 × 2 ÷ time: A 40 N, B 10 N, C 20 N); peak force/injury/durability unmeasured. Guided: B takes four times A's time; average force magnitude is one quarter, not “every force four times smaller.” Task choose observation / inference / unsupported: “B changes shape by 3 cm” is observation (positions 1/3/2 across subitems); “B's average net stopping force is smaller than A's under these assumptions” inference; “B prevents every injury” unsupported. One item per claim with their own support/check/skip. Different example same velocity change, 0.20 versus 0.40 s → longer time, half average magnitude, no peak claim. Hint points to measurement versus model versus missing evidence.
5. **Choose, explain, revise.** Constraints initially cost ≤3, depth ≤4 cm; choose smallest average force magnitude among supplied options: B / A / C (correct first). Guided lists filtering constraints then comparing times at equal velocity change. Hint: first keep only fitting designs, then compare. Different example cost ≤1 admits only A, without implying A safest. Original explanation textarea max 1200 exact characters, ungraded human-read; keep first version. New supplied requirement revealed on request: depth limit 3 cm, cost ≤3, and same measurements; B no longer fits, C is smallest average force among fitting options. Second selection A / B / C (correct third), and independent revision textarea; keep first and latest copies with first explanation/revision. No automated prose judgment. Distinguish constrained toy choice from an approved real protective device. No drops/heights/physical experiment suggestions.

Every task shows teaching plus an optional worked guided case, hint, different example and skip; access never depends on success. Help/meaning/audio requests recorded before outcomes. Supplied choices preserve authored order; no clever overclaim-only distractor pattern. Lesson 4 has three separate items; lesson 5 has two. Total eight supplied items.
