## Frozen families and quantities

Every new source holds its own format1, id, family, question/title, named goods/towns, rule numbers, given quantity/side, prompt, teaching/model notice, separate example, hint and feedback strings. Rendering/checking a saved work uses that source, never today's generator or wording. Current family is explicit at creation and stays fixed until Another card; all families always selectable. Integer size `k` is1–12; it names a multiplier or seedlings per part, never a learner level.

- **Apples for reed (`apples`)**: agreed rate3 baskets of apples for2 bundles of reed. Stock `3*k+r`, where `r` is0,1 or2. Choose as many full trade groups as stock allows. Draft `groups` starts0, editable0–12. Used baskets=`3*groups`; received bundles=`2*groups`. Show stock/used/remaining or shortage with units. Fitting construction: `groups===floor(stock/3)`; any leftover stays home. Do not say all stock is traded or nothing is left over. Example:k2,r1 =>7baskets;2full groups send6baskets, receive4bundles, leave1basket.
- **Reed for apples (`reed`)**: the same agreement, given `2*k+r` bundles, `r`0 or1. Whole groups cost2bundles each and receive3baskets each. Fitting construction uses `floor(stock/2)` groups. Example:k5,r0 =>10bundles,5groups,15baskets. This is the reverse unknown of the same direct ratio, not an inverse-proportion relation. No fractional bundle/basket.
- **Sharing the nursery (`nursery`)**: Vadoalto:Willowbank=`5:3`; supplied total=`8*k` seedlings. Draw5equal part boxes and3equal part boxes, all with the same editable value0–12. Each displayed part shows its seedlings count. Totals are5*value and3*value, not5/3 of the whole. Fitting construction uses `total/(5+3)` in every part. Example40seedlings =>8parts,5seedlings per part, shares25and15. Never treat two traded goods as one conserved total; only nursery shares sum to a single total.

Zero is an empty draft, not a new ratio. Trade shortage says how many more goods the chosen groups need; do not draw negative physical stock. Groups can be added/lifted and parts adjusted before or after checking. No drag-only interaction, automatic reset after mismatch, or answer-entry keyboard required for the model. Mismatch gives a relevant next action and preserves the material. Use distinct icons/patterns and labels; do not communicate town/good only by color. Each one-group picture shows the counts from its frozen rule: today’s new cards use3baskets and2bundles. Nursery part boxes and their labels likewise use the frozen left/right part counts, not hard-coded5/3/eight. Render help, examples, result lists and diagrams from that same frozen source; old4:7or2:1rules must never show today’s default pictures. Totals stay readable without drawing hundreds of objects.

## Changing cards and optional suggestions

Once work exists, Another card preselects the same family and a suggested size; it never silently changes the current card. Explicit family/size choices override suggestions. Generate the remainder deterministically from the monotonic creation serial: apples `(serial-1)%3`, reed `(serial-1)%2`, nursery0. Thus finite cases recur; label a family/rule/given combination found in retained readable visits **A familiar card**. Missing history does not establish novelty: removed or unreadable cards are not an exposure registry. A repeated source is not new distinct learning evidence.
