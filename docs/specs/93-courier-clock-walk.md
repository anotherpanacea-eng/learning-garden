## One new action, after clock setting

At optional **#post/clock-walk**, help the pretend courier describe the time between a supplied departure and arrival. Keep departure fixed, move a coupled clock along a **0–60 elapsed-minute line**, then propose the number of minutes between the two supplied times. The endpoint proposal and duration response are checked separately. This adds a narrow M5-II interval action: a clock label is a position; elapsed minutes measure the interval from a reference that stays fixed.

Actual [Preparation Clock68](68-preparation-clock.md) reads one pictured hour/half-hour and sets another supplied goal, using24 half-hour face slots. It explicitly does not assess elapsed duration. Cartographer's Table measures model route length; Repeat Deliveries and Post Office execute route instructions without time costs. None calculates a duration between supplied clock readings.
