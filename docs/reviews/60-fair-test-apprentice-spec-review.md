## Integration and preservation

The existing #workshop/fair renderer/binder/notes seams support this extension without a new destination or held application changes. The apprentice uses the existing Plan/Try/Tell activity as its host, while adding the distinct action of helping a novice preserve an observation, limit an explanation and demonstrate a focused comparison. The narrowly nested optional child and external open flag are sufficient; no broader router, learner model, authoring system or source mapping is needed.

Opening without an investigation, closing to the unchanged base page, independent drafts, optional exact words, frozen encounter/model content, and distinct demonstration/card/words records are adequately specified. Each check computes only its applicable component. Recorded output is retained by readable shape rather than regraded against current metadata or assumed historical truth. Future/invalid child work can remain opaque and escaped while the ordinary bench remains usable; a future base envelope remains read-only. Cap disclosure, unsafe IDs, malformed siblings, unknown fields and pure views have concrete acceptance requirements.

The existing base help/audio binder is broad enough that the required apprentice scope separation is necessary. The spec explicitly requires that separation, no support creation before a visit, no native-help carry into a new encounter, focused-input preservation, and actual keyboard/focus/narration checks. Those are implementation gates rather than unresolved design questions.

Source dispositions preserve the difference between narrow fair-testing/observation practice and broader physical experimentation, independently authored explanations or Teaching It Back. PR47's proposed role is used without adopting research-effect claims. Existing privacy, local-only prose, license and source-pin boundaries remain intact.

Independent implementation review and the specified actual browser/storage/narration checks remain required before a draft PR. This review makes no physical-device, audible-speech, human screen-reader, independent-explanation or learning-effect claim.
