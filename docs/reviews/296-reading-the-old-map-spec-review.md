## Teaching-content review

Independent Claude Opus reviewed all three authored documents against canonical story text, the proposed Case6 dossier, story120 and the actual page UI. No P1; four P2 teaching findings:

1. Distinguish the writer’s incomplete Scale statement from the app’s illustrative drawing, which is not to scale.
2. Do not assume the missing word before walk is a measure or a time word.
3. Name the drawing as another source for retelling details, not merely the written paragraph and present-day observations.
4. Explain `[smudged word]` as an editor’s notation, not original visible ink; label the reference Source copy.

All four are folded into the spec and teaching text. Minor folds also make the quotation exact, broaden the first gap beyond manner, mark unexplained mill boards as an unknown to investigate, specify frozen helper/limitation sources, label the ferry example outside the Keeper story, and scope unknown word length to this copy. These are bounded teaching/representation clarifications; the four-step operation and storage/entry boundaries are unchanged. Focused independent Claude Sonnet repair review independently checked the folds against actual canonical text and cleared them: zero remaining P1/P2. No implementation behavior was reviewed. Three minor notes are carried into build: speak the marker as “a smudged word,” call the unavailable action an arrival choice, and do not turn the hypothetical further-record prompt into a fabricated link.
