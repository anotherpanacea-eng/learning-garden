# Spec 326 Spanish panel: prompt

This pass follows the method of the [spec 117 panel](../117-spanish-panel/prompt.md), with the same setting and the same three providers. Each reviewer ran alone and saw none of the other reports. The Claude report was written first, before the others came back.

The package each reviewer received had two parts:

1. **The two phrases spec 326 reuses**, with the full Longer paragraphs of chapter 1 (the floating market) and chapter 2 (the seed exchange) from [act-3.md](../../content/120-story/act-3.md) at `77b6d0f`:
   - chapter 1, «¡Pan, cestas, miel!», glossed "Bread, baskets, honey.";
   - chapter 2, «Carrizo», she says. «Reed.»

   The questions: report errors, unnatural or regional wording, and gloss problems, each with a confidence and a verdict. For *carrizo*, say whether it is the right everyday Spain word for this reed in this setting.
2. **Every *junco* line** in the River Market companion ([117 text](../../content/117-river-market-text.md) on main), which calls the same Vadoalto plant *el junco*, glossed "reed". The questions: is *junco* the wrong word for a reed used for baskets and roofs; should both texts use *carrizo*; and which J word should replace *junco* in the sound note (*jardín* was offered as a candidate). Give exact replacement lines for every occurrence, the two word lists included.

The Code-PC runs used a 35-line prompt file holding exactly this package. Their raw outputs are kept on Code-PC beside it.
