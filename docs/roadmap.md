# After the Storm: connected adventures roadmap

This is a plan for this small, parent-guided app, not a complete curriculum or a promise of measured learning gains. Each selected increment receives a bounded specification and independent review before implementation. Delivery order does not lock a child's access: every existing destination remains open. Existing math, stories, companions, and the replayable café remain available.

## Teaching direction

Check [Jane and Marble opportunities](upstream-opportunities.md) before building each learning capability. The first reviewed story pack and tap-to-order response format are implemented, using Jane's pack/publisher conventions and a small validation adaptation. The document distinguishes current reuse from proposed extensions and records upstream revisions.

Treat a successful game loop as a spiral: keep its familiar actions, revisit an idea with changed conditions or representations, and let a new purpose invite another subject. Repetition alone is not evidence of learning; support, familiarity and transfer to another setting stay distinct. Living Garden now uses the same search for animal needs, evidence and changes; direct, sequence and inference notes; and equal-group, inverse and two-step parcel math. Separate suggestions use distinct finished tasks and preserve support, familiarity and retries.

Begin with a purpose worth exploring, build an idea through a controllable visual explanation, invite a change or prediction, and offer a new situation with less support. Children can pause, replay, skip familiar steps, choose another representation, or explore with a grown-up. Learning tasks stay untimed, without grades, streaks, placement claims or a compulsory sequence. Animations explain a change and stay under the learner's control; reduced-motion and keyboard/touch alternatives work throughout.

Keep reading, comprehension, composition, investigation, support, familiarity, and unobserved skills distinct. A prediction is an idea to test, not a scored fact. Clicking an external link does not establish that an experiment was used. Selecting an observation reports what someone noticed; it is not proof of scientific understanding. Word chunks and response choices can support expression without demonstrating independent free writing. Off-screen projects remain invitations.

## Scope shared by all steps

Use the existing static app and public origin. Preserve prior records and the original shared storage value during explorer migration. Browser-local drafts, optional persistence, export, reset, and the chosen guide/explorer apply to every addition. New records stay distinct from original math assessment records. No child-specific source, family stories, identifying fields, uploads, analytics, server learner records, live AI, or background generation. Public examples and tests are fictional or synthetic. Authored content is reviewed before release. Use Marble topic IDs for selected learning connections when a genuine content match is established; do not copy its age labels into a placement system.

Marble's taxonomy is openly licensed data with attribution obligations. Its Water Lab and Ecosystem Simulator are separate external applications; no source-reuse license was found during the current review. Link out explicitly, do not embed or copy their code/assets, and do not transmit garden records. External sites have their own availability and data handling. Local explanation pictures remain original, labeled illustrations, never claimed as observations from another site.

## Release procedure

Each spec is independently reviewed; resolve concrete findings before building that step. Implement only the selected increment. Check its learning content, state transitions, migration, save-off/export/reset, touch/keyboard interaction, and responsive layout. Independent implementation review and root browser QA precede publishing the reviewed static files to the current personal Cloudflare game. Earlier Sites and Cloudflare addresses keep their previous releases. Keep the GitHub PR draft and unmerged until exact-candidate Claude clearance and a separately authorized merge. Future content details, external controls, and scientific models must be refreshed before those steps are built.
