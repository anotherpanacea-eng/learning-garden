## Arrival

**One Shared Point**

The surveyors have two number rules for a future plan. Mark a point. Does that same point fit both rules?

The first coordinate, x, tells how far across. The second, y, tells how far up or down. In (1, 3), x is1 and y is3. The order matters.

A point fits y=mx+b when its chosen y equals the result of mx+b at its chosen x. One rule has infinitely many fitting points. A solution to two rules must fit both at once.

These are number rules over all real x and y, not heights or costs in the town. The picture shows only a window. Our point controls move by halves; that does not limit the mathematical solutions to halves.

## Separate worked example

Rule A: y=2x-2. Rule B: y=-x+7.

Try(1,0). Rule A gives2×1-2=0, so the point fits A. Rule B gives-1+7=6, so the same point does not fit B. Being on the x axis does not make it the shared point.

Try(3,4). A gives2×3-2=4 and B gives-3+7=4. The point fits both. The lines have different slopes, so this is their only shared point. The x coordinate alone is not a complete answer: the shared pair is(3,4).

**Show reasoning** · **Reference opened** · **Reference crossing**

Different slopes: Equate the two outputs. Subtract the Rule B x term and the Rule A start from both sides. Divide by the nonzero difference in slopes. Then substitute x into either rule to find y, and check the same pair in both original equations. These reversible steps give the single shared pair.

Same slope, different starts: The x terms cancel and leave zero equal to a nonzero number. No point can fit both lines. They are distinct parallel lines; not seeing a crossing in this window alone would not prove it.

Same slope, same start: Both rules describe the same line. Infinitely many pairs on that line fit both; points off the line do not. This is not every point in the plane.
