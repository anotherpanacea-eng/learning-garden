# Café touch counter · short copy

Companion to [spec285](../specs/285-cafe-touch-counter.md). Reuse existing `cafe-ui.mjs` story, orders, ingredient names/qualities, guest responses, repair questions/feedback, number questions/help/errors, shortage labels, supper ending and invitations verbatim in their relocated surfaces. No new learning prompt or answer key.

Only the following short interface labels/readouts are added or consolidated:

| Surface | Text |
| --- | --- |
| Inline disclosure | Café tools |
| Extra activity disclosure | More café activities |
| Shelf back | Previous jars |
| Shelf forward | More jars |
| Shelf readout | Shelf {page} of {pages} |
| Plate heading | Your plate |
| Plate count | {chosen} of {needed} bites |
| Filled slot accessible name | Take one {ingredient} off the plate |
| Jar accessible action | Add one {ingredient} to the plate |
| Jar stock | {stock} in the jar |
| Jar chosen count | {count} on your plate |
| Full plate guidance | Your plate is full. Take a bite off to make room. |
| Retained overflow | Outside the requested spaces |
| Empty plate guidance | Tap a jar to add a bite. Tap a bite to take it off. |

Use existing “Check my plate”, “Change my plate”, “Go gathering”, “Hear the order”, “Invite the next guest”, “Invite a different guest”, “Grown-up notes”, and “Take a break” consistently. Singular/plural is grammatical where dynamic counts require it. Keep “Each bite comes from one jar. All food and guests are pretend.” and the existing two-wish explanation reachable in context/tools. Wishes are labeled actual qualities, never icons alone. Shelf number describes navigation, never progress or a learning level.
