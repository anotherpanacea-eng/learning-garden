## Teach cards (167)

Card 1 (A true thing about science), for the Mending Pile:
> An object is a thing with a job. A material is the stuff it is made of. Ask two questions.

Worked example: *Three buckets from the heap.*
1. What is each one? A bucket, a bucket, a bucket.
2. What is it made of? Wood. Metal. Plastic.
3. Same object. Three different materials.

Card 3, for the Shape Bench:
> Pushing and pulling can change a solid's shape. Some materials spring back. Some keep the new shape. Some hardly change, or snap.

Worked example: *Clay and a rubber strip.*
1. Squash the clay. Let go. It stays flat.
2. Stretch the rubber. Let go. It springs back.
3. Both are still clay and rubber.

## (c) The Shape Bench

**167:** Prompt: Choose a sample and an action. Predict first. · Predict chips: Springs back · Keeps new shape · Hardly changes or snaps · Actions: Squash · Bend · Twist · Stretch · then Let go · Prediction matched: You predicted that. Now you've seen it. · Prediction didn't match: Surprise! Different materials answer differently. · Willow note: Dry willow cracks. Basket makers soak it first, so it bends.

**Samples (167):** Clay · Soaked willow rod · Rubber strip · Sponge · Slate · Rope

## Grown-up notes

**What this teaches (new, trimmed from 167):** the difference between an object and its material, and how squashing, bending, twisting and stretching affect different materials.

**What it does not claim (new, trimmed from 167):** the bench results are authored, simplified pictures, not measurements. It does not explain properties with particles. A sorted card is a supported sort, not proof that a child can name materials unaided.
