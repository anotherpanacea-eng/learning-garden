## Teaching pages (six), each with a separate numeric example

1. **Two clues stay on the table.** A row is an equality. If both originals are true for a pair, adding their left sides and adding their right sides gives another true equality. Keep the originals: the new row alone may fit extra pairs. Example A=(1,1,6), B=(1,-1,2), factors(1,1), add, pair(4,2), preview/check true, reference false.
2. **Multiply every part.** Multiplying a whole equality by a nonzero number keeps its solutions. Include both letter columns AND the number on the right. Choose factors to make opposite coefficients before adding. Example A=(1,2,5), B=(2,-1,0), factors(1,2), add, pair(1,2), preview/check/reference true.
3. **Zero loses a clue.** Multiplying by zero changes any row to 0=0. That is true for every pair. It cannot tell us which pairs fit the originals. Even two zeroed rows do not show that the originals share every pair. Example A=(1,1,6), B=(1,-1,2), factors(0,0), add, pair(0,0), preview/check true, reference false.
4. **A contradiction matters.** If a combination of the originals requires zero to equal a nonzero number, no pair can make both originals true. Example A=(1,1,3), B=(2,2,8), factors(2,1), subtract, pair null, preview true, check false, reference true.
5. **A repeated clue is still a line.** Here the second original is exactly twice the first, including the right side. They describe the same line of pairs. That is not every pair in the plane. Check (1,2), then discuss why (0,0) does not fit. Example A=(1,1,3), B=(2,2,6), factors(2,1), subtract, pair(1,2), preview/check/reference true.
6. **Keep fractions exact.** Your mixture gives 3x=5. Dividing both sides by3 gives x=5/3. Substituting in the first original gives 2(5/3) + y = 5, so y = 5 - 10/3 = 5/3. A rounded decimal is not needed. Check the exact pair in both originals. Example A=(2,1,5), B=(1,-1,0), factors(1,1), add, pair(5/3,5/3), preview/check/reference true.

## Exact generated display and speech templates

Signed equation format: `{a}x + {b}y = {c}`, omit zero variable terms and coefficient1, use minus rather than `+ negative`, parentheses around negative/fractional factors. A zero variable expression renders0; raw `0x` can appear in the column table when explaining cancellation. Each row has three aligned cells and an equals sign, not a balance-scale image claiming physical masses.

Scaled cell: `({factor}) × ({coefficient}) = {product}`. Result column: `{scaledA} + {signedScaledB} = {combined}`, with subtract displayed as subtraction of the parenthesized B coefficient when selected. Eligible magnitude: `Magnitude {abs(left)} × {abs(right)} = {abs(product)}`. These exact products, including constants, are the only factor-exposure inputs here.

Pair product: `({coefficient}) × ({n}/{d}) = {coefficient*n}/{d}` with the final result reduced. State signed numerator multiplication explicitly; show eligible magnitude alongside. Sum the exact reduced products and compare with own c: `Row A: {ax} + {by} = {sum}; the original asks for {c}.` Use minus for negative terms; sums show every sign unambiguously. Repeat B. A pair check never uses only the combined row.

Worked route: `Multiply A by {factorA} and B by {factorB}, then add` (factors follow the spec's sign-normalized deterministic route; D0 retains unnormalized nonzero factors). Show all signed coefficient products and all resulting column sums. For one remaining coefficient C and constant R: `{C}{variable} = {R}; divide both sides by {C}: {variable} = {R/C}`. Then select the FIRST original with nonzero other coefficient and display substitution, subtraction from c and division by that coefficient; finally both-original check. Show determinant/cross-products as signed factor products before their exact sum/difference; for coincident/no-pair cases show both variable-to-constant cross comparisons, not only variable determinant. Reference values derive from the source, never from the proposed pair.
