All notices are original Willowbank fiction. Selected ideas adapt project277's Red Pencil proposal; no external lesson prose, dictionary definition or art is copied. Six independent, freely available supplied tasks. Keep unfinished or unexpected versions. Checks concern these supplied requests, not a child's prose or ability.

## Shared teaching and example

Header: Read the reader's request. What change would help?

Teaching introduction: Revising changes writing for its reader. Editing checks spelling, punctuation and similar conventions. They can overlap; sort these examples by their main job.

Different worked example title: A note for a gardener.

Manual parts (one additional part per tap):
1. “Meet by the thing.” The gardener has never been here. Change it to “Meet by the greenhouse.” That clarifies the place: revising.
2. Another note says “Meet by the greenhous.” Change greenhous to greenhouse. That fixes the spelling in this separate note: editing.
3. “A lovely garden” and “a beautiful garden” can both fit a friendly welcome. A preference need not be a correction.

Read together: Use revisionCopy.together from the complete bench copy below.

Human application: Use revisionCopy.invitation and its actual messageLabel link below.

Grown-up note: Revising and editing are overlapping processes, not a universal two-box taxonomy. The classification task supplies clear main-purpose examples. Notice checks use each frozen reader request; they do not assess independent composition or the truth of original prose. The writer may keep a stylistic preference. Existing original messages and case-note revision remain separate, with their own saving choices.

##1 · pencil-notice · A notice for a visitor · sort

Reader: A first-time visitor needs the bakery's opening time, location and entrance. This is a brief visit notice, not delivery instructions.

Prompt: Make a notice for this visitor.

Five paper strips, in this order, with stable IDs:
- time: The bakery opens at seven in the morning.
- place: The bakery is on the square, next to the post office.
- flour: Leave flour sacks at the side door.
- pause: Deliveries pause from noon to one in the afternoon.
- front: Visitors use the front door.

Headings: use = On this notice; aside = Set aside for this reader.
Key: time/place/front -> use; flour/pause -> aside.
Every strip remains movable; setting aside does not erase it or mean it is false.
Frozen other-reader invitation: Make a notice for the courier -> pencil-courier.

Per-strip different feedback:
- time: This reader asked when the bakery opens. The time helps them plan.
- place: This visitor needs to find the bakery. Keep its location available.
- flour: This line is for a flour delivery. This visitor's request does not need it.
- pause: This pause applies to deliveries, not the visitor's opening-time question.
- front: The visitor asked which entrance to use. This line answers that.

Fit: The notice answers this visitor's three requests. Set-aside lines remain available for another reader.
General: Compare each line with this reader's request.
Hint: Which lines answer opening time, location and entrance?
Example: A gardener who needs a meeting place benefits from “Meet by the greenhouse.” A lunch story would not answer that request.
Steps: Read the reader's request. Choose a strip. Put it on the notice or set it aside.

##2 · pencil-courier · A notice for a flour courier · sort

Reader: A flour courier already knows the address, opening time and visitors' entrance. They need where to leave sacks and when deliveries pause.
Prompt: Make a notice for this courier.
Frozen other-reader invitation: Make a notice for the visitor -> pencil-notice.
Same five strips, order and headings as1. Key: flour/pause -> use; time/place/front -> aside.

Per-strip different feedback:
- time: The courier already knows the opening time. This brief request is about drop-off and delivery pauses.
- place: The courier already knows the address. They need the drop-off instructions here.
- flour: This line names the drop-off door. The courier needs it.
- pause: This line says when deliveries pause. The courier needs it.
- front: The visitors' entrance is already known. Flour sacks go to the side door.

Fit: The notice answers this courier's two requests. A line useful to a visitor need not belong on this brief notice.
General: Check the request, not whether a sentence is interesting or true. Unfinished versions can be kept.
Hint: Which lines tell this courier where to leave sacks and when deliveries pause?
Example: A gardener who knows the meeting place may instead need which gate is unlocked. Useful details depend on the request.
Steps: Read this reader's request. Choose from the five strips. Decide what this notice needs.

##3 · pencil-changes · What is the change's main job? · sort

Reader: Pip wants to understand why someone changed a notice. These clear examples ask for the main job; other changes can do both jobs.
Prompt: Sort these changes by their main job.
Headings: revise = Revise for the reader; edit = Edit spelling or punctuation.
Parts and keys:
- spelling: Change “bred” to “bread” when naming the food. -> edit
- location: Add where the bakery is so visitors can find it. -> revise
- period: Add a missing period to finish a full written sentence. -> edit
- order: Put opening times first so visitors can find them quickly. -> revise

Per-part different feedback:
- spelling: Here the food is already intended. This change fixes the spelling used for it.
- location: This adds information the reader needs. Its main job is revising the content.
- period: The sentence's meaning is already clear. This change supplies its expected end punctuation.
- order: This reorganizes information for the reader. Its main job is revising the order.

Fit: These examples separate the main jobs. Real revision and editing can overlap.
General: Ask what this particular change mainly does. This is practice with these examples, not a rule for every change.
Hint: Is the main job revising for the reader, or editing spelling or punctuation?
Example: In one note, change “the thing” to “the greenhouse” to clarify the place. In a separate note, change “greenhous” to “greenhouse” to edit spelling.

##4 · pencil-edit · A word for the food · choice

Reader: A bakery visitor needs the ordinary spelling of the food in this sentence.
Prompt: Which spelling names the food here?
Original part draft: The bakery sells bred.
Options in stable order:
- bread: bread [KEY, position1]
- bred: bred
- breed: breed
Preview for each: “The bakery sells {option}.”
Fit: Bread names this food. This correction is an example of editing.
Different bred: Bred is a different word. Here the sentence is naming the food bread.
Different breed: Breed is a different word. The food in this sentence is bread.
General: Use the sentence's meaning. These printed choices are support, not a spelling-from-memory check.
Hint: The sentence is naming food you might buy at the bakery.
Example: “Please bring teh plates” needs the spelling the in place of teh. The intended word is already known.

##5 · pencil-plan · A plan for reaching the show · choice

Reader: A visitor at the bridge needs to reach today's show on time. The note gives its place, start time and a usable marked route.
Prompt: Which plan serves this reader?
Parts:
- place: Today's show is at the Story Loft.
- time: It starts at six in the evening.
- route: From the bridge, follow the star signs to the Story Loft.
Options in stable order:
- history: Describe the old show and name each past actor.
- arrival: Use today's place, start time and marked route. [KEY, position2]
- wait: Wait for every earlier route to be fully mapped.
No preview map: use the existing generic original facts plus Your choice, preserving the selected plan literally before Check.
Fit: The given place, time and current route answer this visitor's request. A plan starts with what the reader needs.
Different history: Past actors do not tell this visitor how to reach today's show on time.
Different wait: A usable current route is already given. Earlier routes are not needed for this visit.
General: Match the plan to the stated purpose; do not add a requirement the supplied facts do not need.
Hint: What does this visitor need to do now?
Example: A first-time bakery visitor needs the opening time, place and entrance more than the history of every bun.

##6 · pencil-taste · A preference is not always a correction · choice

Reader: A story reader only needs to understand that Pip ran with speed. Compare the two versions for this purpose.
Prompt: Which versions can fit this purpose?
Parts:
- fast: Version 1: “Pip ran fast.”
- quickly: Version 2: “Pip ran quickly.”
Options in stable order:
- first: Only the first can work.
- second: Only the second can work.
- both: Both can work. [KEY, position3]
- neither: Neither can work.
No preview map: use the existing generic versions plus Your choice. Every Only/Both/Neither claim stays literal in current and kept previews; no correction before Check.
Fit: Fast can be an adverb here, and quickly also works. A writer may prefer either without calling the other a mistake.
Different first: You may prefer fast. That does not make quickly incorrect for this purpose.
Different second: You may prefer quickly. Fast is also a standard adverb here.
Different neither: Both versions can describe running with speed here. There is no need to reject both.
General: Explain your preference to a person. This check asks what can work, not what you must like.
Hint: A standard adverb does not always end in -ly.
Example: A friendly reading-room sign could describe a quiet corner or a peaceful corner. A writer may prefer one effect without calling the other incorrect.
