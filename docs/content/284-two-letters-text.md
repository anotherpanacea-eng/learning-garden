## Set A · five supplied-choice items

Options stay in the order below. Each fitting choice has feedback as well as each alternative. All prompts keep their complete source available. The relevant letter is council except a3, which uses Nuria.

### a1

Line: **We ___ a copy of your readings.**
Prompt: **Which formal word keeps the asking meaning?**

1. `ask-for`: **ask for** — alternative, informal-for-formal. **That asks clearly too. Request is the more formal choice for this brief.**
2. `request`: **request** — fits, suits-brief. **Request means ask for. The letter is asking for a copy.**
3. `require`: **require** — other, changed-meaning. **Here require says the copy is necessary. This letter is asking for a copy.**

Hint: **Look at card 3. Asking for something, or saying it is necessary?**
Explanation: **Request keeps the asking meaning. Require changes what this line says.**

## Three teaching cards

### card1 · Formal and informal

**Formal and informal language suit different situations. Register means language choices for a situation. Think about the reader and the job. Neither is better, and a formal letter need not use long words.**

Worked steps:

1. **A friendly note to Nuria: Hi Nuria!**
2. **A formal council letter: Dear Members of the Council,**
3. **Both say hello. The readers and the briefs differ.**

### card2 · One word for two

**Formal writing sometimes uses a one-word verb where a friendly note uses two: find out → discover, ask for → request, go in → enter. Check the meaning too.**

Worked steps:

1. **We would like to ask for a copy.**
2. **For this formal letter, try request in place of ask for.**
3. **We would like to request a copy. The letter is still asking.**

### card3 · Keep the meaning

**Request means ask for. Require can mean need or make necessary. Here, saying a copy is necessary changes the original request. Formal words are not all interchangeable.**

Worked steps:

1. **We request a copy. We ask for one.**
2. **We require a copy. Here, we say it is necessary.**
3. **Willowbank is asking for the copy. Request keeps that meaning.**
