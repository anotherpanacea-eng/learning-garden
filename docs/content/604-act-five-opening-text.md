## How every project works

**Title:** How every project works

**Intro:** Each project has the same six steps. A small project is a whole project too.

**Steps** (adapted from the script's step table, second person). The shared lines are copied from the script unchanged:
- Pick a path, or a smaller version of it.
- Say what you don't know yet.
- Make a first version, using any job.
- Change one thing, or keep it as it is and say why.
- Write one thing the project can't tell us yet.

(The Show step's own wording, "Someone sees it, uses it, or says something about it.", is unchanged from the script.)

**Switching** (adapted from the script, second person): You may change paths, shrink a path, or start a second one. Nothing is lost when you switch.
