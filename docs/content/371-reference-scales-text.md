## Optional glossary and grown-up interpretation

Precision: “How closely repeated readings agree under stated conditions.”
Accuracy: “How close a reading is to a reference value.”
Reference: “The comparison value given by this model.”
Adjustment: “A number added to each reading in a separate preview.”
Range: “Highest reading minus lowest reading.”
