## Primary mathematics/teaching sources

[CCSS5.NF.B.4a](https://www.thecorestandards.org/Math/Content/5/NF/B/4/a/) supports interpreting a fraction of an amount; [4b](https://www.thecorestandards.org/Math/Content/5/NF/B/4/b/) connects fraction products with rectangular areas. Read the actual official pages. These support the mathematical interpretation, not an age placement or claim of broad standards completion.

Read IES/WWC's [Developing Effective Fractions Instruction, recommendation3, printed pp28–29/Figure7](https://ies.ed.gov/ncee/wwc/docs/practiceguide/fractions_pg_093010.pdf), including the actual rendered diagram. It distinguishes the original whole from a selected fractional amount and then a portion of that amount. This informs keeping both referents visible. It does not establish that this particular digital implementation improves learning. No source diagram or wording is copied.

For a supplied `b × d` equal-cell grid, choosing `x` first columns and `y` rows of that first amount selects `x*y` cells of the original `b*d`. A zero first amount gives zero for every second selection; taking all rows preserves a positive first amount. These integer identities need finite independent mathematical checking before build. The field is fictional and idealized; there is no historical, botanical, survey, land-area or harvest claim requiring a real-world source.
