# My Count Collection: source and overlap audit

Prepared 2026-10-22 for [spec86](../specs/86-count-collection.md). This is a bounded curriculum/design study, not a new graph pin, efficacy finding or incorporation of source lesson text.

The official [Common Core 2.MD.D.10](https://www.thecorestandards.org/Math/Content/2/MD/) covers picture/bar graphs with small numbers of categories and simple comparisons. [3.MD.B.3](https://www.thecorestandards.org/Math/Content/3/MD/) adds scaled categorical displays and comparison problems. These were read directly on 2026-10-22. The first activity uses three categories, a shared baseline and one/two-step axis labels; it does not cover every representation, multistep comparison or an entire grade. Standards do not validate this game or place a child.
