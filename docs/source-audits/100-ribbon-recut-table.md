# Ribbon Recut Table: source and overlap audit

Prepared 2026-10-22 for [proposed spec 100](../specs/100-ribbon-recut-table.md). This is an authoring audit, not an independent spec review, runtime test, atlas update, or learning-effect claim.

## Existing work and the irreducible increment

Inspected actual [Fraction Trail spec 52](../specs/52-fraction-trail.md), [Same Amount, New Cuts spec 70](../specs/70-same-amount-new-cuts.md), [Lantern Line spec 89](../specs/89-lantern-line.md), their current core/UI modules, and the Workshop dispatch. Fraction Trail already divides a fixed whole, moves a flag, accepts equivalent written readings and compares kept/current half-family routes. Same Amount, New Cuts already supplies an equivalent fixed reference and asks for a matching endpoint in a specified different partition; its six cases include both split and join **directions** for halves, thirds and sixths. Lantern Line already asks for the order of two actual positions. Neither of the first two makes **the cuts themselves** the reversible action while keeping the same current amount and flag fixed through each cut. Spec 100 does that and nothing more: old boundaries remain, new midpoints appear, two counts change, and Join removes those midpoints. Reusing the existing local 12-tick convention directly would make eighths of quarters nonintegral; the transient diagram uses 24 exact internal positions. This is a local rendering scale, not a changed old save or a new arithmetic engine.

The current atlas already has a narrowly qualified `mt_FbDKeLfBCo` reference for Same Amount, New Cuts. This authoring pass adds no atlas reference or topic count. It does not claim that old equivalent readings, a new question wording, or a second static aligned strip are by themselves novel.

## Primary mathematical references and limits

- The [NCETM equivalent-fractions topic 3.7](https://www.ncetm.org.uk/classroom-resources/primm-307-finding-equivalent-fractions-and-simplifying-fractions/) describes equal numerical value across changed numerators/denominators and a general multiplicative relationship. Spec 100 pictures only doubling every equal unit in five authored cases and its reversal; it does not ask for simplification, a formula, or a general algorithm.
- The [NCETM non-unit-fractions topic 3.3](https://www.ncetm.org.uk/classroom-resources/primm-303-non-unit-fractions-identifying-representing-and-comparing/) identifies a non-unit fraction as several equal unit fractions. That supports counting `2/3 → 4/6 → 8/12` and `3/4 → 6/8` as equal-size units, without confusing number of parts with amount.
- The [Illustrative Mathematics 3.NF.A.3 standards page](https://im.kendallhunt.com/standards) states equivalence as equal size or the same point and gives simple visual-model examples. Its [grade 3 fraction sequence](https://im.kendallhunt.com/K5_ES/teachers/grade-3/course-guide/scope-and-sequence.html) describes decomposing each fractional part into smaller parts or grouping neighboring parts into larger ones while the represented amount remains the same. Spec 100's reversible controls model exactly that finite physical idea, while keeping the common whole and endpoint explicit. The sequence also distinguishes same-size strips from later number-line point reasoning. No source drawing, worksheet, task, or prose is copied into child-facing material.

Equal whole width, equal part widths, fixed shaded endpoint, and old/new seam styles are required for truthful diagrams. A larger denominator here means smaller equal pieces, **not** more colored ribbon. A higher numerator follows from recounting the same colored stretch in smaller units; it is not an independent arithmetic result. The worked `1/6 → 2/12 → 1/6` example is visibly separate from all five cases. There is no real cloth measurement, transfer to differently sized wholes, ratio/rate claim, full equivalence proof, or inference about the learner from a button press. The original [mock](../specs/assets/100-ribbon-recut-table.svg) is authored for this spec, not copied from NCETM, IM, Jane or Marble.
