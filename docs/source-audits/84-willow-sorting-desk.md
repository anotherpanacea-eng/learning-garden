## Existing app boundary

`dist/post-office-core.mjs` already executes at most six literal `go`, `then`, `there` and `give` cards one at a time. It freezes each delivery order and logs destination or handoff results; it does not inspect a parcel feature or choose a branch. `dist/post-office-ui.mjs` has the Willow Post Office hub and a sorting counter used to **pack** an arithmetic quantity, not to sort stamp/color inputs. `dist/instruction-core.mjs` and [spec 54](../specs/54-instructions-for-a-reader.md) model supplied action order and a reader's available information; they never execute a conditional. The new desk borrows the local practices of literal step trace, reset on edit, supplied request versus actual machine behavior, optional help and saved-source custody. It does not extend a delivery visit, turn original prose into code, or reuse the instruction runner as an if/else interpreter.
