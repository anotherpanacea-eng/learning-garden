# The Number Garden

A small, parent-guided math prototype: a six-question informal check-in, six-question multiplication practice sets, and six authored puzzles across three freely selectable paths.

Serve `dist/` with any static HTTP server. It has no install/build step, external assets, AI calls, analytics, or application backend. The Site is configured in `.openai/hosting.json`.

Progress is saved only in the browser's local storage. Grown-up notes provide a persistence switch, a JSON download, and confirmed clearing. New devices and browsers start fresh. Assessment drafts retain hints and attempts across reloads; a practice set's in-progress plan does not resume after reload, but recorded answers remain.

Adaptation is deliberately small: equal-groups observations suggest visual practice; encountered fact pairs that need support or another try are revisited; correctly derived answers remain positive observations and can lead to optional fact familiarity practice. Sparse or skipped assessments get a neutral mix. Practice never overwrites the original check-in. Previously encountered related examples are marked. Challenges stay open.

This is not a validated assessment, a full multiplication inventory, a grade-level estimate, or a class-placement recommendation. The parent selects the observed method; the app does not judge a spoken explanation. Try fresh examples together on later days.
